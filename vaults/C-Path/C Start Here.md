# C Start Here

> [!abstract] Why this matters
> C is the language under operating systems, drivers, embedded devices, network stacks and most of the security bugs you'll ever read about. Learn C and you learn how a computer really handles memory, which is exactly what both developers and security people need to understand.

> [!holocron] How this vault works
> Every note has the same shape, so you always know where to look:
> 1. **Why this matters**, at the top.
> 2. The idea, in short sections.
> 3. Code. In the workbench (with the switch on **C**), **Try in sandbox** runs it.
> 4. **Try it**: the exercise or example that goes with it.
> 5. A **Dark side** box: the trap most people fall into.
> 6. **Check yourself** questions, folded. They also become flashcards in Revise (Ctrl+Shift+V).
> 7. What's next.
>
> A note takes 5 to 15 minutes. You don't have to finish a phase in one go.

## Daily habit (15 to 45 minutes is plenty)

- **Start**: Learn → Where was I?
- **Focus**: Ctrl+Shift+G, one thing, a timer.
- **Do**: one note, or one exercise step.
- **Finish**: one line in [[C Done Log]].

> [!tip] Stuck?
> The **?** next to an error explains it. The note's Dark side box usually names the trap. A break usually does the rest.
