# 0.2 The Workbench for C

> [!abstract] Why this matters
> A few keys do almost everything. Learn them once, and you can stop thinking about the tools and think about your code.

## Switch to C

The toolbar has a **C | C++** switch. You can also press Ctrl+Shift+J.

When **C** is lit:

- new files are `.c` files,
- the sandbox and the judge use C,
- programs are built with gcc and the 2017 version of C.

A `.c` file is always treated as C, whatever the switch says.

## The keys

| Key | What it does |
|---|---|
| **Ctrl+F9** | Build and run this file. |
| **F9** | Build only. |
| **F7** | Check the exercise you're doing, or run the tests. |
| **Ctrl+Shift+D** | Start the debugger, stopped at the line your cursor is on. |
| **F4** | Open the C sandbox, a place for quick experiments. |
| **Ctrl+Shift+H** | Look up a function, like `printf` or `malloc`. |
| **Ctrl+Shift+P** | Find any command by typing its name. |

## Where to practise

- **Learn**, on the toolbar, has the exercises. The C basics track goes with Phases 1 to 4. The Security lab goes with Phase 6.
- **Sandbox** (F4) is for quick experiments. Its list of examples includes the "break it" programs.
- **Memory view** (Learn → Visualise memory) shows variables as boxes and pointers as arrows.

## Try it

1. Set the switch to **C**.
2. Choose File → New file → Program. Call it `hello`, and save it in a folder like `~/c-path`.
3. Press Ctrl+F9. Your program builds and runs.
4. Open Learn → **First functions**. Press F7 to check your work.

> [!sith] The dark side
> Writing a whole program before you compile it once. Compile every few lines instead. Then each error is small, and it's close to what you just typed.

## Check yourself

> [!question]- What changes when you set the toolbar switch to C?
> New files, new projects, the sandbox and the judge all use C. Header files (.h) are treated as C too.

> [!question]- How do you look up a C library function without leaving the workbench?
> Put your cursor on the function's name and press Ctrl+Shift+H. The built-in reference opens. It also has a button for the function's man page.
