# Projects: Start Here

> [!abstract] Why this matters
> A project makes you use many things together, the way real work does. Each project comes with starter code and tests. The Tests sidebar shows how many tests pass.

| Project | What you'll use | When to do it |
|---|---|---|
| C01 Word Count | Loops, characters and input | After Phase 1 |
| C02 Contact Book | Structs, strings and files | After Phase 4 |
| C03 Dynamic Array Library | malloc, realloc, and designing functions for others | After Phase 3 |
| C04 Hash Map | Hashing and who owns each piece of memory | After Phase 5 |
| C05 Packet Parser | Reading data you can't trust, safely | After Phase 6 |

> [!boss] Boss fight
> Each project's last test is the case people forget. It might be empty input, the biggest possible value, or input that lies about its own size. Pass it before you move on.
