# 2.06 Multi-dimensional Arrays

> [!abstract] Why this matters
> Grids are everywhere: maps, game boards, images and tables of numbers. In C, a 2D array is really one long row, stored one line of the grid at a time. Knowing this makes the indexes easy to work out.

## An example

```c
#include <stdio.h>

#define ROWS 3
#define COLS 5

/* the column count must be known to index a 2D array */
static void draw(const char grid[][COLS], int rows) {
    for (int r = 0; r < rows; r++) {
        for (int c = 0; c < COLS; c++) putchar(grid[r][c]);
        putchar('\n');
    }
}

int main(void) {
    char map[ROWS][COLS];
    for (int r = 0; r < ROWS; r++)
        for (int c = 0; c < COLS; c++)
            map[r][c] = '.';
    map[1][2] = 'X';                     /* the base */
    map[0][4] = '*';
    draw(map, ROWS);

    /* row-major: map[r][c] sits at offset r * COLS + c */
    const char *flat = &map[0][0];
    printf("flat[1*COLS+2] = %c\n", flat[1 * COLS + 2]);
    printf("sizeof map = %zu\n", sizeof map);
    return 0;
}
```

- `char map[ROWS][COLS]` makes a grid with 3 rows and 5 columns.
- `map[1][2]` is row 1, column 2.
- A function that takes a 2D array needs to know how many columns it has. That's why `draw` says `grid[][COLS]`.

## How a grid sits in memory

C stores the whole of row 0 first. Then the whole of row 1, and so on. This is called **row-major order**.

So `map[r][c]` is `r * COLS + c` places from the start. The example shows this with the `flat` pointer.

For speed, loop over rows on the outside and columns on the inside. Then you read memory in order, which is fast. On a big grid, swapping the two loops makes it noticeably slower.

> [!sith] The dark side
> Mixing up rows and columns, like writing `map[c][r]`. On a grid that isn't square, this reads or writes outside the grid, with no warning.

## Check yourself

> [!question]- In char g[3][5], how far from the start is g[2][1]?
> It's 2 × 5 + 1 = 11 places from the start.

> [!question]- Which loop order reads a 2D array in memory order?
> Rows on the outside, and columns on the inside.
