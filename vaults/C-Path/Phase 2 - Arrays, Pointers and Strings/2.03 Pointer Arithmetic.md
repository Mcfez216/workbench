# 2.03 Pointer Arithmetic

> [!abstract] Why this matters
> Adding 1 to a pointer moves it to the next element, not the next byte. This one rule explains why `a[i]` works, and why pointers have types.

## An example

```c
#include <stdio.h>

int main(void) {
    int parsecs[] = {12, 14, 9, 30};
    size_t n = sizeof parsecs / sizeof parsecs[0];
    int *p = parsecs;                   /* the array decays to &parsecs[0] */

    printf("p   = %p\np+1 = %p (moved %zu bytes)\n",
           (void *)p, (void *)(p + 1), sizeof *p);
    printf("parsecs[2] = %d, *(p + 2) = %d\n", parsecs[2], *(p + 2));   /* the same thing */

    for (int *it = parsecs; it != parsecs + n; it++)   /* walk with a pointer; stop at one-past-the-end */
        printf("%d ", *it);
    printf("\n");

    int *last = &parsecs[n - 1];
    printf("elements between: %td\n", last - p);       /* subtracting pointers counts elements */
    return 0;
}
```

## The rules

- `p + 1` moves to the next element. For an `int`, that's usually 4 bytes further on. In general, `p + i` moves `i * sizeof *p` bytes.
- `a[i]` means exactly the same as `*(a + i)`. Square brackets are a short way to write it.
- If two pointers point into the same array, `last - p` tells you how many elements are between them. You print that with `%td`.
- You may point to the place just after the last element, to mark the end. But you must never read or write there.

## Try it

1. Click **Try in sandbox** and run the example.
2. Change every `int` in it to `double`. Run it again.
3. Now `p + 1` moves 8 bytes, because a double is 8 bytes.
4. Open it in Learn → **Visualise memory**, and step through the loop.

> [!sith] The dark side
> Moving a pointer outside its array, like `p - 1` or `p + n + 1`. It's undefined behaviour even if you never read through it. C only promises things for addresses inside the array, plus the one just after its end.

## Check yourself

> [!question]- If int *p is at address 1000, and an int is 4 bytes, where is p + 3?
> It's at 1012. It moves 3 elements, and each one is 4 bytes.

> [!question]- What does a[i] really mean?
> It means *(a + i). Move i elements on from a, then use the value there.

> [!question]- Can you point one past the end of an array? Can you read there?
> You can point there, for example to mark where the array ends. But reading or writing there is undefined behaviour.
