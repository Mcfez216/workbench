# 2.02 Pointers

> [!abstract] Why this matters
> A pointer is a variable that holds an address. An address says where something is stored in memory. Arrays, strings and most of the powerful parts of C are built on pointers.

## The picture to keep in your head

Think of memory as a long row of boxes. Every box has a number, called its **address**.

A normal variable is a box that holds a value, like `40`.

A pointer is a box that holds the address of *another* box.

## Two symbols

- `&x` means "the address of x".
- `*p` means "the box that p points to". Using `*` like this is called **dereferencing**.

## An example

```c
#include <stdio.h>

/* This function gets the address of the fuel, so it can change the real fuel. */
static void refuel(int *tank, int amount) {
    if (tank == NULL) return;   /* NULL means "points to nothing". Stop here. */
    *tank += amount;            /* change the box that tank points to */
}

int main(void) {
    int fuel = 40;
    int *p = &fuel;             /* p holds the address of fuel */

    printf("fuel=%d, &fuel=%p, p=%p, *p=%d\n", fuel, (void *)&fuel, (void *)p, *p);
    *p = 55;                    /* this changes fuel */
    refuel(&fuel, 10);
    printf("fuel is now %d\n", fuel);

    int *nothing = NULL;        /* a pointer that points to nothing, on purpose */
    refuel(nothing, 5);         /* safe, because refuel checks for NULL */
    printf("sizeof(int*) = %zu\n", sizeof p);
    return 0;
}
```

When you run it, `&fuel` and `p` print the same address. `*p` prints the same value as `fuel`.

## Why functions need pointers

When you call a function, C gives it a **copy** of each value. This is called **passing by value**. If the function changes its copy, your variable doesn't change.

To let a function change your variable, give it the variable's address. Then the function can go to that address and change the real thing.

This is why `scanf("%d", &x)` needs the `&`. Without it, `scanf` couldn't put the number into `x`.

## Try it

1. Open this example in **Learn → Visualise memory**.
2. Step through it line by line. You'll see an arrow from `p` to `fuel`.
3. Watch `fuel` change when the line `*p = 55;` runs.
4. Now click **Try in sandbox**. Delete the line `if (tank == NULL) return;`.
5. Run it. The program crashes, and the sanitizer reports a **SEGV**. A SEGV means the program tried to use memory it isn't allowed to touch. Here, that's address 0.

> [!sith] The dark side
> A pointer you never gave a value to holds random leftover memory. So it points somewhere random. Writing through it, like `int *p; *p = 5;`, can damage other data or crash the program. Always give a pointer a value when you make it: a real address, or `NULL`.

## Check yourself

> [!question]- If p == &x, what is *p?
> `*p` is `x` itself. Reading `*p` gives you the value of `x`. Writing to `*p` changes `x`.

> [!question]- Why does a function need a pointer to change your variable?
> C gives a function a copy of each value. With only a copy, it can't reach your variable. If you pass the variable's address, the function can go to that address and change the original.

> [!question]- What should a pointer hold if it doesn't point at anything yet?
> It should hold `NULL`. That makes it easy to check, and the program won't use random memory by mistake.
