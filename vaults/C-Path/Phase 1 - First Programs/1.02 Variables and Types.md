# 1.02 Variables and Types

> [!abstract] Why this matters
> In C a type decides exactly how many bytes a value takes and how they're read. Pick the wrong one and numbers wrap around or lose their fractions, silently.

## The basic types

| Type | Holds | Usual size | printf |
|---|---|---|---|
| `int` | whole numbers | 4 bytes (±2.1 billion) | `%d` |
| `long long` | bigger whole numbers | 8 bytes | `%lld` |
| `unsigned int` | 0 and up only | 4 bytes | `%u` |
| `size_t` | sizes and counts | 8 bytes | `%zu` |
| `double` | decimals | 8 bytes | `%f` |
| `char` | one byte (a character) | 1 byte | `%c` |
| `bool` (`<stdbool.h>`) | true / false | 1 byte | `%d` |

## sizeof and the limits

```c
#include <limits.h>
#include <stdio.h>

int main(void) {
    printf("int:       %zu bytes, %d to %d\n", sizeof(int), INT_MIN, INT_MAX);
    printf("long long: %zu bytes\n", sizeof(long long));
    printf("double:    %zu bytes\n", sizeof(double));
    printf("char:      %zu byte\n", sizeof(char));

    int count = 0;          /* always give a variable a value */
    double average = 0.0;
    char grade = 'A';
    printf("%d %.1f %c\n", count, average, grade);
    return 0;
}
```

## Always initialise

A local variable without a value holds whatever bytes were there before: garbage, different each run.

```c
int total;      /* garbage */
total += 5;     /* undefined behaviour */
```

## Try it

- **Try in sandbox**. Then Learn → Visualise memory on it: before each line runs, look at what the variables hold.
- Change `int count = 0;` to `int count;` and use it: what does `-Wall` say?

> [!sith] The dark side
> Storing a size or a count in an `int` and comparing it with `strlen()` or `sizeof` (which are unsigned): -1 turns into a huge number and the comparison lies. Use `size_t` for sizes.

## Check yourself

> [!question]- How many bytes is an int on a typical 64-bit Linux system, and what's its range?
> 4 bytes, from -2147483648 to 2147483647 (INT_MIN to INT_MAX).

> [!question]- What printf conversion prints a size_t?
> %zu.

> [!question]- What's in a local variable you didn't initialise?
> Whatever bytes were left in that memory; reading it is undefined behaviour.
