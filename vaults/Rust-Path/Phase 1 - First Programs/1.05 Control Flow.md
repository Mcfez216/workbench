# 1.05 Control Flow

> [!abstract] Why this matters
> Decisions and loops let a program do more than one fixed thing. Rust's loops are designed to avoid the classic off-by-one mistake, by going through things directly instead of counting.

## An example

```rust
fn main() {
    let fuel = 35;

    if fuel > 50 {
        println!("Ready for the Kessel Run.");
    } else if fuel > 20 {
        println!("Enough for a short hop.");
    } else {
        println!("Refuel first.");
    }

    // for: through a range. 0..3 is 0, 1, 2. 1..=3 is 1, 2, 3.
    for i in 1..=3 {
        println!("countdown {}", 4 - i);
    }

    // for: through a list, without counting at all
    let crew = ["Han", "Chewie", "Leia"];
    for name in crew {
        println!("aboard: {name}");
    }

    // while: as long as something is true
    let mut shields = 3;
    while shields > 0 {
        shields -= 1;
    }

    // loop: forever, until break. break can give a value.
    let mut tries = 0;
    let found = loop {
        tries += 1;
        if tries == 4 {
            break tries * 10;
        }
    };
    println!("shields {shields}, found {found} after {tries} tries");
}
```

## The ranges

| Range | Gives |
|---|---|
| `0..3` | 0, 1, 2. The end isn't included. |
| `0..=3` | 0, 1, 2, 3. The `=` includes the end. |
| `(0..3).rev()` | 2, 1, 0. Backwards. |

## Going through a list

`for x in list` gives you each item. There's no index to get wrong. If you also need the position, use `for (i, x) in list.iter().enumerate()`.

## Try it

1. Click **Try in sandbox**, and run it.
2. Change `1..=3` to `1..3`. What changes in the countdown?
3. Change the crew loop to print each name with its position, using `.iter().enumerate()`.

> [!sith] The dark side
> Writing C-style index loops, like `for i in 0..v.len() { v[i] }`, when you only need the items. `for x in &v` is shorter, and can't go past the end.

## Check yourself

> [!question]- What numbers does 0..3 give, and what does 0..=3 give?
> 0..3 gives 0, 1 and 2. 0..=3 gives 0, 1, 2 and 3.

> [!question]- How does a loop give back a value?
> With break followed by the value, like break tries * 10;

> [!question]- How do you get each item and its position in a for loop?
> for (i, x) in list.iter().enumerate()
