# 1.06 Input and Output

> [!abstract] Why this matters
> Input is where your program meets the outside world, and the outside world can type anything. Rust makes you handle "that wasn't a number" on purpose, instead of carrying on with a garbage value.

## Reading a line

```rust
use std::io;

fn main() {
    println!("Your name and age?");
    let mut line = String::new();
    io::stdin().read_line(&mut line).expect("couldn't read input");

    let mut words = line.split_whitespace();
    let name = words.next().unwrap_or("stranger");
    let age: u32 = match words.next().map(|w| w.parse()) {
        Some(Ok(n)) => n,
        _ => {
            println!("That age isn't a number, so I'll guess 0.");
            0
        }
    };
    println!("Hello, {name}! In ten years you'll be {}.", age + 10);
}
```

1. `String::new()` makes an empty string to read into.
2. `read_line(&mut line)` reads one line into it. The `&mut` lets it change your string.
3. `.expect(...)` stops the program with that message if reading fails. That only happens if the input is closed.
4. `split_whitespace()` splits the line into words.
5. `parse()` turns text into a number. It gives back a `Result`, because the text might not be a number. The `match` handles both cases.

## Printing

| Write | Gives |
|---|---|
| `println!("{x}")` | The value, then a new line |
| `print!("{x}")` | The value, with no new line |
| `eprintln!("{x}")` | The value, to the error output instead |
| `println!("{x:?}")` | The value, the debugging way, for lists and structs |
| `println!("{x:.2}")` | A decimal number, with 2 places |

## Try it

1. Click **Try in sandbox**, and run it.
2. In the terminal, type `Han 42` and press Enter.
3. Run it again. This time type `Han forty`. The program says so, instead of stopping.

> [!sith] The dark side
> Writing `.parse().unwrap()` on input from a person. If they type a word, the program panics. Handle the error, like the example does.

## Check yourself

> [!question]- Why does read_line need &mut line?
> It needs to change your string, by adding the line to it. &mut lets it borrow the string to change it.

> [!question]- What does parse() give back?
> A Result. It's Ok with the number if the text was a number, or Err if it wasn't.

> [!question]- What's the difference between println! and eprintln!?
> println! prints to the normal output. eprintln! prints to the error output, which is kept separate.
