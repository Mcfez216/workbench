# 0.2 Rust in MHDE

> [!abstract] Why this matters
> MHDE uses the same keys for Rust as for C and C++. If you already know them, there's nothing new to learn. If you don't, this is the only list you need.

## Switch to Rust

The toolbar has a **C | C++ | Rust** switch. You can also press Ctrl+Shift+J, which goes round all three.

When **Rust** is lit:

- new files are `.rs` files,
- new projects are Cargo projects,
- the sandbox and the judge use Rust.

A `.rs` file is always treated as Rust, whatever the switch says.

## The keys

| Key | What it does in Rust |
|---|---|
| **F9** | Build. A lone `.rs` file uses `rustc`. A Cargo project uses `cargo build`. |
| **Ctrl+F9** | Build and run, in a terminal, so the program can read your typing. |
| **F7** | Run the tests, with `cargo test`. In an exercise, check your work. |
| **Ctrl+Shift+D** | Start `rust-gdb`, stopped at the line your cursor is on. |
| **Ctrl+Shift+K** | Ask clippy for advice. |
| **Ctrl+Shift+O** | Tidy the file with rustfmt. |
| **F4** | Open the Rust sandbox. |

## When something goes wrong

- A **compile error** appears in the Problems list, at its line. Click the **?** for a plain-words explanation. Click **rustc --explain** for the compiler's own long explanation.
- A **panic** means the program stopped on purpose, because something was wrong. For example, an index past the end of a list. Its line turns red, with the reason underneath.

## Try it

1. Set the switch to **Rust**.
2. Press F4 to open the sandbox. Press Ctrl+F9. It prints a greeting.
3. Load the example **Break it: index out of bounds (panic)**. Run it. The line turns red.
4. Load **Break it: use after move (compile error)**. Run it. Click **?** next to the error.

> [!sith] The dark side
> Ignoring the compiler's long messages. Rust's errors are some of the most helpful of any language. They often say exactly how to fix the problem, in a "help:" line.

## Check yourself

> [!question]- What does Ctrl+F9 do with a lone .rs file, and with a file in a Cargo project?
> With a lone file, it compiles that file with rustc and runs it. In a Cargo project, it builds the project with cargo and runs its program.

> [!question]- What is a panic?
> The program stopping on purpose, because something went wrong that it can't continue from. Rust shows the line and the reason.
