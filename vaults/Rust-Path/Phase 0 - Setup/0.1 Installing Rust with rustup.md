# 0.1 Installing Rust with rustup

> [!abstract] Why this matters
> Rust's tools all come from one installer, called rustup. It keeps them up to date, and in step with each other. Ten minutes now gives you everything you need for this whole vault.

## What you get

| Tool | What it does |
|---|---|
| `rustc` | The Rust compiler. It turns your code into a program. |
| `cargo` | Rust's project tool. It builds, runs and tests projects, and downloads libraries. |
| `rust-analyzer` | Helps the editor. It shows errors and suggestions while you type. |
| `clippy` | Reads your code and suggests better ways to write it. |
| `rustfmt` | Tidies your code into the standard layout. |
| `rust-gdb` | The gdb debugger, set up to show Rust values clearly. |

## Installing it

MHDE's installers do this for you. The Ubuntu, WSL and Windows setups all install Rust with rustup.

To do it by hand on Linux or WSL:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs -o rustup-init.sh
sh rustup-init.sh -y
rustup component add rust-analyzer clippy rustfmt
```

The first line downloads the installer. Read it first if you like. The second runs it.

## Check it worked

In MHDE, open **Help → Which tools are installed?** You should see `rustc`, `cargo`, `rust-analyzer`, `clippy-driver` and `rustfmt` ticked.

Or in a terminal:

```bash
rustc --version
cargo --version
```

## Try it

1. Check your tools, as above.
2. Run `rustup update`. It updates Rust to the newest stable version.
3. Run `rustup doc --book`. It opens "The Rust Programming Language", the official book, offline.

> [!sith] The dark side
> Installing Rust from your Linux distribution's packages, like `apt install rustc`. They're often a year or more out of date, and too old for the 2024 edition this vault uses. Use rustup.

## Check yourself

> [!question]- What does rustup do?
> It installs Rust's tools, keeps them up to date, and keeps them in step with each other.

> [!question]- What's the difference between rustc and cargo?
> rustc compiles Rust code. cargo manages whole projects: it calls rustc for you, runs tests, and downloads libraries.
