# 4.08 Clippy, rustfmt and Docs

> [!abstract] Why this matters
> Three tools come with Rust, and every Rust project uses them. **clippy** suggests better ways to write your code. **rustfmt** lays it out in the standard style. **rustdoc** turns your comments into documentation. They make your code look like everyone else's Rust, so others can read it easily.

## clippy

clippy knows hundreds of patterns that work, but could be clearer or faster. In MHDE, press **Ctrl+Shift+K**. Its advice appears in Problems.

```rust
fn main() {
    let crew = vec!["Han", "Leia"];
    let mut count = 0;
    for i in 0..crew.len() {        // clippy: use an iterator instead of an index
        println!("{}", crew[i]);
        count += 1;
    }
    if count == 0 {
        println!("empty");
    }
}
```

clippy says this loop only uses `i` to index `crew`, so it should be `for name in &crew`. It also points out the `vec!` could be a plain array.

## rustfmt

Press **Ctrl+Shift+O** to tidy a file. There's one standard style, so nobody argues about where the brackets go. A `rustfmt.toml` file can change a few settings, like the line width.

## Documentation comments

```rust
/// Works out the fuel for a jump.
///
/// Returns `None` if the answer is too big for a `u32`.
///
/// # Examples
///
/// ```
/// assert_eq!(fuel_for(12), Some(120));
/// ```
pub fn fuel_for(parsecs: u32) -> Option<u32> {
    parsecs.checked_mul(10)
}

fn main() {
    println!("{:?}", fuel_for(12));
}
```

- `///` comments document the thing below them. They're written in Markdown.
- `cargo doc --open` turns them into web pages.
- The example in a doc comment is run as a test by `cargo test`. So the documentation can't go out of date.

## Try it

1. Paste the first example into a file, and press Ctrl+Shift+K. Read clippy's advice.
2. Fix it the way clippy says, and run clippy again.
3. Mess up the layout of a file on purpose, then press Ctrl+Shift+O.

> [!sith] The dark side
> Turning clippy warnings off with `#[allow(...)]` without reading them. Most of them are right. When one isn't, allow it on that one line, with a comment saying why.

## Check yourself

> [!question]- What does clippy do?
> It reads your code and suggests clearer, faster or more usual ways to write it.

> [!question]- What does /// mean in Rust?
> A documentation comment for the item below it. cargo doc turns these into web pages.

> [!question]- Why can't an example in a doc comment go out of date?
> cargo test runs it as a test, so it fails if the code changes and the example is wrong.
