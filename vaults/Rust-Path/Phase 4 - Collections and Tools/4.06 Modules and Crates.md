# 4.06 Modules and Crates

> [!abstract] Why this matters
> A real program has many parts. **Modules** split your code into named sections, and decide what other parts can see. **Crates** are whole libraries, and Cargo downloads them for you.

## Modules

```rust
mod navigation {
    pub struct Course {
        pub destination: String,
        parsecs: u32,                       // private: only this module can see it
    }

    impl Course {
        pub fn new(destination: &str, parsecs: u32) -> Course {
            Course { destination: destination.to_string(), parsecs }
        }
        pub fn fuel(&self) -> u32 {
            helpers::fuel_for(self.parsecs)
        }
    }

    mod helpers {
        pub fn fuel_for(parsecs: u32) -> u32 {
            parsecs * 10
        }
    }
}

use navigation::Course;

fn main() {
    let c = Course::new("Kessel", 12);
    println!("to {}: {} fuel", c.destination, c.fuel());
}
```

- `mod name { ... }` makes a module.
- Everything is **private** unless it's marked `pub`. Private means only its own module, and the modules inside it, can use it.
- `use navigation::Course;` lets you write `Course` instead of `navigation::Course`.

## Modules in files

In a Cargo project, `mod navigation;` (with a semicolon) in `main.rs` or `lib.rs` loads the module from `src/navigation.rs`. A module with its own sub-modules can be a folder: `src/navigation/mod.rs`.

## Crates

A **crate** is a library or a program. Libraries from crates.io are added with `cargo add`:

```bash
cargo add rand
```

That adds a line under `[dependencies]` in `Cargo.toml`. The next build downloads it.

## Try it

1. Click **Try in sandbox**, and run it.
2. In `main`, try `println!("{}", c.parsecs);`. Read the error: the field is private.
3. In a Cargo project, move `navigation` into its own file, `src/navigation.rs`, and write `mod navigation;` in `main.rs`.

> [!sith] The dark side
> Marking everything `pub` to make the errors stop. Private fields are how a type keeps its rules, like `fuel` never going above `max_fuel`. Make public only what other code really needs.

## Check yourself

> [!question]- Are things in a module public or private by default?
> Private. You mark them pub to let other modules use them.

> [!question]- What does mod navigation; with a semicolon do in a Cargo project?
> It loads the module from src/navigation.rs, or from src/navigation/mod.rs.

> [!question]- How do you add a library from crates.io?
> cargo add name. It adds the library to Cargo.toml, and the next build downloads it.
