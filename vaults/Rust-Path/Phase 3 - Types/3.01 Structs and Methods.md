# 3.01 Structs and Methods

> [!abstract] Why this matters
> A **struct** groups related values into one type of your own, like a Ship with a name and a fuel level. **Methods** are functions that belong to that type. Together they let your code talk about ships and pilots, instead of loose numbers and strings.

## An example

```rust
#[derive(Debug)]
struct Ship {
    name: String,
    fuel: u32,
    max_fuel: u32,
}

impl Ship {
    // an "associated function": called as Ship::new(...), with no self
    fn new(name: &str, max_fuel: u32) -> Ship {
        Ship { name: name.to_string(), fuel: 0, max_fuel }
    }

    // &self: reads the ship
    fn fuel_left(&self) -> u32 {
        self.max_fuel - self.fuel
    }

    // &mut self: changes the ship
    fn refuel(&mut self, amount: u32) {
        self.fuel = (self.fuel + amount).min(self.max_fuel);
    }
}

fn main() {
    let mut falcon = Ship::new("Millennium Falcon", 100);
    falcon.refuel(70);
    falcon.refuel(50);                 // can't go past max_fuel
    println!("{} has {} fuel, room for {}", falcon.name, falcon.fuel, falcon.fuel_left());
    println!("{falcon:?}");
}
```

- `struct Ship { ... }` lists the **fields** and their types.
- `impl Ship { ... }` holds the methods.
- `&self` means the method borrows the ship to read it. `&mut self` borrows it to change it.
- A function in `impl` without `self`, like `new`, is called with `Ship::new(...)`. `new` is the usual name for one that makes a value.
- `#[derive(Debug)]` lets you print the whole struct with `{:?}`.

## Field shorthand

In `Ship { name: ..., fuel: 0, max_fuel }`, writing just `max_fuel` means `max_fuel: max_fuel`. It's a shortcut for when a variable has the same name as the field.

## Try it

1. Click **Try in sandbox**, and run it.
2. Add a method `fn is_full(&self) -> bool`, and print it.
3. Remove `mut` from `let mut falcon`. Read the error: `refuel` needs `&mut self`.

> [!sith] The dark side
> Making every field public with `pub` and changing them from outside. Then nothing stops someone setting `fuel` above `max_fuel`. Keep fields private, and change them through methods that keep the rules.

## Check yourself

> [!question]- What's the difference between &self and &mut self in a method?
> &self borrows the value to read it. &mut self borrows it to change it.

> [!question]- What is Ship::new?
> An associated function: a function in the impl block without self. new is the usual name for one that makes a new value.

> [!question]- What does #[derive(Debug)] do?
> It lets you print the whole struct with {:?}, which is useful when debugging.
