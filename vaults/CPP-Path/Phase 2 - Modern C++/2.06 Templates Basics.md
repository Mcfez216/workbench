# 2.06 Templates Basics

> [!abstract] Why this matters
> A **template** lets you write code once, and use it with any type. That's how `std::vector<T>` works for ints, strings and your own classes. You'll mostly use templates rather than write them. But knowing how they work makes their long error messages easier to read.

## An example

```cpp
#include <concepts>
#include <iostream>
#include <string>

template <typename T>
T largest(const T& a, const T& b) {
    return (a < b) ? b : a;
}

// C++20 concepts: say what the type must be able to do
template <std::integral T>
T half(T x) { return x / 2; }

template <typename T>
struct Pair {            // a class template
    T first, second;
    T sum() const { return first + second; }
};

int main() {
    std::cout << largest(3, 9) << '\n';                                 // T = int
    std::cout << largest(std::string("Han"), std::string("Leia")) << '\n';  // T = std::string
    std::cout << half(11) << '\n';
    // half(2.5);   // error: double doesn't satisfy std::integral, and the message says so
    Pair<double> p{1.5, 2.25};
    std::cout << p.sum() << '\n';
    return 0;
}
```

- `largest` is a **function template**. `T` stands for "some type". The compiler works out `T` from what you pass in.
- `half` uses a **concept**, `std::integral`. A concept says what a type must be able to do. Here, `T` must be a whole-number type.
- `Pair` is a **class template**. You choose the type when you use it, like `Pair<double>`.

## How it works

For each type you use, the compiler writes a separate copy of the code. That's why templates live in header files. The compiler needs the whole template to write each new copy.

## Reading template errors

When something goes wrong deep inside a template, the compiler prints a long chain of "required from here" lines. **Look for the first line that's in your own file.** That's the one that matters. The workbench's Problems list jumps there for you, and folds the rest away.

## Try it

1. Click **Try in sandbox** and run it.
2. Remove the `//` in front of `half(2.5);`.
3. Build it. You get a short, clear error, because the concept says `double` isn't allowed.
4. Learn → **Algorithms and lambdas** uses templates you don't see.

> [!sith] The dark side
> Writing a template when a normal function would do. Templates are powerful. But each one makes compiling slower and errors harder to read.

## Check yourself

> [!question]- Why are templates usually written in header files?
> Wherever a template is used, the compiler needs its whole code, so it can make a version for each type.

> [!question]- What does a concept like std::integral do?
> It limits which types a template accepts. If you use the wrong type, you get a short, direct error.

> [!question]- In a long template error, which line do you read first?
> The first line that points at your own code.
