# Projects: Start Here

> [!abstract] Why this matters
> Exercises teach one idea at a time. Projects make you combine them, the way real work does. Each project has a stub (your half-finished version) and a set of tests; the Tests sidebar shows how many pass, so you always know how far along you are.

## How a project works

1. Read the project note.
2. Open the stub (Tests sidebar → the project's name).
3. Make one test pass at a time: ▶ runs the stub's tests, Shift+F7 runs the one your cursor is in.
4. Stuck for 20 minutes? Take a break, then the project note's hints. ☼ peeks at the solution if you must.

> Each project's last test is a boss: the edge case everyone forgets. Beat it before you move on.
