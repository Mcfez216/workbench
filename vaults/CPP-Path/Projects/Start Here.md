# Projects: Start Here

> [!abstract] Why this matters
> Exercises teach one idea at a time. Projects make you use them together, the way real work does. Each project has starter code and a set of tests. The Tests sidebar shows how many tests pass, so you always know how far you've got.

## How a project works

1. Read the project's note.
2. Open the starter code. In the Tests sidebar, click the project's name.
3. Make one test pass at a time. ▶ runs the project's tests. Shift+F7 runs just the test your cursor is in.
4. Stuck for 20 minutes? Take a break. Then read the hints in the project's note. If you really need to, ☼ shows the solution.

> [!boss] Boss fight
> Each project's last test is a "boss". It's the case people forget, like empty input or a huge value. Pass it before you move on.
