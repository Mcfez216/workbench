# 1.04 Functions and Overloading

> [!abstract] Why this matters
> Functions are how you break a problem into pieces small enough to get right. C++ lets several functions share a name when their parameters differ, which reads well, but you need to know which one gets picked.

## A good function

- Does **one** thing, and its name says what.
- Takes what it needs as parameters, returns its result.
- Is short enough to see at once (often under 20 lines).

```cpp
#include <iostream>
#include <string>

// overloads: same name, different parameters
void show(int x) { std::cout << "int " << x << '\n'; }
void show(double x) { std::cout << "double " << x << '\n'; }
void show(const std::string& s) { std::cout << "string " << s << '\n'; }

// a default argument
std::string greet(const std::string& name, const std::string& greeting = "Hello") {
    return greeting + ", " + name + "!";
}

int main() {
    show(3);                     // int
    show(3.0);                   // double
    show(std::string("three"));  // string
    std::cout << greet("Luke") << '\n';
    std::cout << greet("Leia", "Help me") << '\n';
    return 0;
}
```

## How the compiler picks

It looks at the argument types and picks the best match: an exact match beats a conversion. If two are equally good, it's an **ambiguous call** error. `show(3.0f)` (a float) converts to double happily; `show('a')` would pick int.

## Try it

- **Try in sandbox**, then add `show(3L);` (a long). Is it ambiguous? Why?
- Learn → **Loops** for practice writing small functions.

> [!sith] The dark side
> Output parameters everywhere (`void compute(int in, int& out1, int& out2)`). Return a value, or a small struct: it's clearer and just as fast.

## Check yourself

> [!question]- When is a call to an overloaded function ambiguous?
> When two or more overloads match equally well (each needs a conversion of the same rank), so the compiler can't choose.

> [!question]- What's the better alternative to several output reference parameters?
> Return a value; for several results, return a small struct (or std::pair / std::tuple) with named members.
