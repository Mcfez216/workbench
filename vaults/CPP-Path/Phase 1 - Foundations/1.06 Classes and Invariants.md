# 1.06 Classes and Invariants

> [!abstract] Why this matters
> A class isn't just a box of data. It's a promise that its data always makes sense. Keep that promise in one place, the class, and the rest of your program can stop checking.

## What an invariant is

An **invariant** is a rule that's true for every valid object. For example:

- A temperature is never below absolute zero.
- A date is always a real date.
- A bank balance never goes negative.

Three things keep the rule true:

1. The **constructor** makes it true, or refuses to make the object.
2. The **member functions** keep it true.
3. **private** data means no other code can break it.

## An example

```cpp
#include <iostream>
#include <stdexcept>

class Temperature {
public:
    explicit Temperature(double kelvin) : kelvin_(kelvin) {
        if (kelvin < 0.0) throw std::invalid_argument("below absolute zero");
    }

    double kelvin() const { return kelvin_; }
    double celsius() const { return kelvin_ - 273.15; }

    void cool(double by) {
        kelvin_ = (by >= kelvin_) ? 0.0 : kelvin_ - by;   // keeps the invariant
    }

private:
    double kelvin_;   // invariant: kelvin_ >= 0
};

int main() {
    Temperature hoth(200.0);   // the ice planet
    hoth.cool(500.0);
    std::cout << "Hoth: " << hoth.celsius() << " C\n";
    try {
        Temperature impossible(-5.0);
    } catch (const std::invalid_argument& e) {
        std::cout << "refused: " << e.what() << '\n';
    }
    return 0;
}
```

The constructor refuses a temperature below zero kelvin by throwing an error. `cool` never lets the temperature go below zero either.

## The small words

| Word | What it means |
|---|---|
| `public:` and `private:` | Who may use which parts of the class |
| `const` after a member function | The function promises not to change the object |
| `explicit` | The constructor won't be used to convert a value without you asking |
| `struct` | A class whose members are public by default. Use it for plain data with no rule to protect. |

## Try it

1. Click **Try in sandbox** and run it.
2. In `main`, add the line `hoth.kelvin_ = -1;`
3. Build it. The compiler stops you, because `kelvin_` is private.
4. For practice, open Learn → **A first class**.

> [!sith] The dark side
> Writing a "get" and a "set" function for every member. A `setKelvin(-5)` function would get round the rule. Offer actions that make sense instead, like `cool` and `heat`.

## Check yourself

> [!question]- What is a class invariant, and who looks after it?
> It's a rule that's always true for a valid object. The constructor makes it true, the member functions keep it true, and private data stops other code breaking it.

> [!question]- What does const after a member function's brackets mean?
> The function promises not to change the object. That means you can call it on const objects too.

> [!question]- When should you use struct instead of class?
> For plain data with no rule to protect, where every member can be set to anything.
