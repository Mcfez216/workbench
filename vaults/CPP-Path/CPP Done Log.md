# CPP Done Log

> [!abstract] Why this matters
> This is a record of what you did, in your own words. On a bad day, it shows you've still made progress. On any day, it's the quickest way to remember where you were.

Write one line each time you study. Put the newest line at the top. The workbench's project journal (Learn → Project journal) does the same for each project.
