# 0.3 Neovim and Editor Keys

> [!abstract] Why this matters
> This note is optional. If you already use Vim or Emacs keys, the workbench understands them. If you don't, the standard keys are fine, and you can skip this note.

## Choose your keys

Open Options → Editor keys. Choose one:

- **Standard**: the usual keys, like Ctrl+S and Ctrl+C.
- **Vim**.
- **Emacs**.

With Vim or Emacs keys, the function keys and the Ctrl+Shift keys still control the workbench.

## Vim keys that do workbench things

| Type this | What it does |
|---|---|
| `:w` | Save. |
| `:CMakeBuild` or `\cb` | Build. |
| `:CTestAll` or `\ct` | Run all the tests. |
| `:CTestHere` or `\cf` | Run the test your cursor is in. |
| `gd` / `gr` | Go to where something is defined / used. |
| `:A` | Switch between the header file and the source file. |
| `:Format` | Tidy the file. |

## The same in real Neovim

You can set up the same commands in Neovim itself. You'd use clangd, and a few lines of settings. You don't need this for the path, because the workbench already does all of it.

> [!sith] The dark side
> Spending your first week setting up an editor instead of writing C++. Pick something, start, and change it later if you want.

## Check yourself

> [!question]- In Vim mode, how do you build, and then run all the tests?
> `\cb` builds. `\ct` runs every test. You can also type `:CMakeBuild` and `:CTestAll`.
