# CPP Start Here

> [!abstract] Why this matters
> C++ is the language under game engines, browsers, databases, flight software and most of the tools you'll use as a developer or a security person. This path takes you from your first program to writing, testing, debugging and attacking (your own) C++ like a professional, one small step at a time.

> [!holocron] How this vault works
> Every note has the same shape, so you always know where to look:
> 1. **Why this matters**, at the top.
> 2. The idea, in short sections.
> 3. Code. In the workbench, **Try in sandbox** runs it.
> 4. **Try it**: the exercise or example that goes with it.
> 5. A **Dark side** box: the trap most people fall into.
> 6. **Check yourself** questions, folded. They also become flashcards in Revise (Ctrl+Shift+V).
> 7. What's next.
>
> A note takes 5 to 15 minutes. You don't have to finish a phase in one go, or do things in order inside a phase.

## The first hour

1. [[0.1 Installing the Toolchain]]: check the tools are there.
2. [[0.2 The Workbench Tour]]: the keys you'll use every day.
3. Copy the vault's code out: File → Copy the vault's code. It becomes `~/cpp-path`, your workspace.
4. Alt+F9 configures, F9 builds, F7 runs the tests.
5. [[1.01 Why CPP and the Compile-Link Model]].

## Daily habit (15 to 45 minutes is plenty)

- **Start**: Learn → Where was I? shows where you stopped.
- **Focus**: Ctrl+Shift+G, one thing, a timer.
- **Do**: one note, or one exercise step.
- **Finish**: one line in [[CPP Done Log]], and a note to future you ("Next I'll...").

> [!tip] Stuck?
> Read the error's **?** in Problems first. Then the note's Dark side box. Then take a break: a surprising number of bugs fix themselves on the walk back.
