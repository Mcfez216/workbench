# CPP Start Here

> [!abstract] Why this matters
> C++ is the language behind game engines, web browsers, databases and many tools you'll use every day. This path takes you from your first program to writing, testing and debugging C++ properly. You'll also learn to find security bugs in your own code. You go one small step at a time.

> [!holocron] How this vault works
> Every note has the same parts, in the same order, so you always know where to look.
> 1. **Why this matters** is at the top.
> 2. Then the idea, in short sections.
> 3. Then some code. In the workbench, click **Try in sandbox** to run it.
> 4. **Try it** gives you something to do, in numbered steps.
> 5. **The dark side** shows one common mistake.
> 6. **Check yourself** has questions. Click one to see the answer. They also become flashcards in Revise (Ctrl+Shift+V).
> 7. A link to the next note.
>
> A note takes 5 to 15 minutes. You don't have to finish a phase in one go. Inside a phase, you can do the notes in any order.

## Your first hour

1. Read [[0.1 Installing the Toolchain]] and check your tools are there.
2. Read [[0.2 The Workbench Tour]] to learn the keys you'll use every day.
3. Choose File → Copy the vault's code. It goes into `~/cpp-path`, your workspace.
4. Press Alt+F9 to set up the project, F9 to build it, and F7 to run the tests.
5. Read [[1.01 Why CPP and the Compile-Link Model]].

## A daily habit

15 to 45 minutes a day is plenty.

1. **Start** with Learn → Where was I? It shows where you stopped.
2. **Focus** with Ctrl+Shift+G. Pick one thing and start the timer.
3. **Do** one note, or one step of an exercise.
4. **Finish** by writing one line in [[CPP Done Log]]. Add a note to your future self, like "Next I'll...".

> [!tip] Stuck?
> First, click the **?** next to the error in Problems. It explains the error in plain words. Then read the note's "dark side" box. If you're still stuck, take a short break. Many bugs are easier to see when you come back.
