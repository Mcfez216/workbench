# 3.03 Algorithms and Iterators

> [!abstract] Why this matters
> The `<algorithm>` header has over a hundred ready-made, tested loops, each with a name. For example sort, find, count and remove. A named algorithm says what the loop is for. A hand-written loop makes the reader work it out.

## Iterators: a position in a container

An **iterator** marks a position in a container.

- `begin()` points at the first element.
- `end()` points one *past* the last element. It's a marker, not an element.

Algorithms take a pair of iterators, a start and an end. That way, they work with any container.

## An example

```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <string>
#include <vector>

struct Pilot { std::string name; int kills; };

int main() {
    std::vector<int> scores{42, 7, 99, 7, 13, 64};

    std::sort(scores.begin(), scores.end());                         // 7 7 13 42 64 99
    auto total = std::accumulate(scores.begin(), scores.end(), 0);
    auto sevens = std::count(scores.begin(), scores.end(), 7);
    auto big = std::find_if(scores.begin(), scores.end(), [](int s) { return s > 50; });

    // erase-remove: remove() shuffles the keepers forward, erase() trims the tail
    scores.erase(std::remove(scores.begin(), scores.end(), 7), scores.end());
    // C++20 says it in one call: std::erase(scores, 7);

    std::cout << "total " << total << ", sevens " << sevens << ", first over 50: " << *big << '\n';
    for (int s : scores) std::cout << s << ' ';
    std::cout << '\n';

    std::vector<Pilot> squad{{"Wedge", 7}, {"Biggs", 2}, {"Luke", 9}};
    auto best = std::max_element(squad.begin(), squad.end(),
                                 [](const Pilot& a, const Pilot& b) { return a.kills < b.kills; });
    std::cout << "ace: " << best->name << '\n';
    return 0;
}
```

- `std::sort` puts the scores in order.
- `std::accumulate` adds them all up.
- `std::count` counts how many are 7.
- `std::find_if` finds the first one that passes a test. The test here is a lambda.
- `erase` with `remove` takes out every 7. In C++20, `std::erase(scores, 7)` does the same in one call.
- `std::max_element` finds the biggest, using your own comparison.

## The ones to learn first

`sort`, `find` and `find_if`, `count` and `count_if`, `any_of` and `all_of`, `min_element` and `max_element`, `accumulate`, `transform`, `remove_if` with `erase`, `reverse`, `unique`, and `binary_search` and `lower_bound`. The last two only work on sorted data.

> [!sith] The dark side
> Calling `std::remove` without `erase`. `remove` doesn't make the container smaller. It moves the values you keep to the front, and leaves junk at the end. The size stays the same until you `erase` the junk.

## Check yourself

> [!question]- What does end() point to?
> One past the last element. It's only a marker, not an element, so you must never read through it.

> [!question]- Why do you need erase after remove?
> remove only moves the values you keep to the front, and tells you where they end. erase then removes the leftover junk at the back.

> [!question]- What must be true before you use binary_search or lower_bound?
> The values must already be sorted.
