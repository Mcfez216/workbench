# 3.08 Choosing a Container

> [!abstract] Why this matters
> A short list makes the choice quick. And the answer is nearly always the same one, which is a relief.

## The list, in order

1. **Start with `std::vector`.** It's fast to go through, and simple.
2. Is the number of things fixed while compiling? Use `std::array`.
3. Do you look things up by a key, like a name? Use `std::unordered_map`. If you need the keys sorted, use `std::map`.
4. Do you only need to know "have I seen this before?" Use `std::unordered_set` or `std::set`.
5. Do you add and remove at both ends? Use `std::deque`.
6. Do you need first in, first out? Use `std::queue`. Do you always want the biggest first? Use `std::priority_queue`.
7. Only use `std::list` if you've measured, and you really need it.

For small amounts of data, a vector usually beats a "cleverer" container. The processor reads memory that sits together much faster.

## An example

```cpp
#include <iostream>
#include <queue>
#include <vector>

int main() {
    // biggest first: the most urgent repair on the Falcon
    std::priority_queue<std::pair<int, const char*>> repairs;
    repairs.push({2, "hyperdrive (again)"});
    repairs.push({9, "hull breach"});
    repairs.push({5, "compressor"});
    while (!repairs.empty()) {
        std::cout << repairs.top().first << ": " << repairs.top().second << '\n';
        repairs.pop();
    }
    std::queue<int> line;   // first in, first out
    line.push(1); line.push(2);
    std::cout << "next: " << line.front() << '\n';
    return 0;
}
```

A `priority_queue` always gives you the biggest value first. Here, that's the most urgent repair. A `queue` gives you things in the order they went in.

> [!sith] The dark side
> Choosing `std::list` because "inserting is fast". Finding the place to insert is slow. And jumping from node to node all over memory is slow too.

## Check yourself

> [!question]- Which container should you start with, and why?
> std::vector. Its elements sit side by side, so it's fast to go through, and it's simple to use.

> [!question]- Which container always gives you the biggest element first?
> std::priority_queue.
