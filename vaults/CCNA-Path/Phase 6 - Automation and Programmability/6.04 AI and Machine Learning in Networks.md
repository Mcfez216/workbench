# 6.04 AI and Machine Learning in Networks

> [!abstract] Why this matters
> Networks produce far more logs and measurements than people can read. AI tools find the patterns. The current CCNA exam asks you to describe how AI and machine learning help run a network. It doesn't ask you to build one.

## The words

- **AI**, artificial intelligence, is software that does tasks that normally need human thinking.
- **Machine learning**, or ML, is a kind of AI that learns patterns from data, instead of following rules a person wrote.
- **Generative AI** makes new content, like text or configuration, from a request in plain language. A chat assistant is generative AI.
- **Predictive AI** uses past data to say what will probably happen next.

## How they're used in networks

| Use | What it does |
|---|---|
| Finding anomalies | Learns what normal traffic looks like, and warns when something is different. For example, a sudden spike that might be an attack. |
| Predicting problems | Spots a link or device that's starting to fail, before users notice. |
| Finding the root cause | Links many alarms together to show the one fault behind them. |
| Capacity planning | Predicts when a link will be too busy. |
| Wireless tuning | Picks channels and power levels for access points automatically. |
| Security | Spots malware traffic, even when it's encrypted, by its patterns. |
| Assistants | Answers questions in plain language, like "Why is the Leeds office slow?", and suggests fixes or configuration. |

Cisco builds these into Catalyst Center, Meraki and its security products.

## Using AI safely

- **Check what it suggests.** Generative AI can sound sure and still be wrong. Read a suggested configuration as carefully as one from a new colleague.
- **Keep secrets out.** Don't paste passwords, keys or private configurations into a public AI tool.
- **Keep a person in charge** of changes that could take the network down.

## Lab

There's no Packet Tracer lab for this note.

1. Pick a broken lab from [[3.05 Troubleshooting Method]].
2. Write down the symptoms as you'd describe them to an assistant.
3. Fix it yourself first. Then compare: would the description you wrote have been enough to find the cause?

> [!sith] The dark side
> Pasting a suggested configuration straight onto a live device. An AI can invent a command that doesn't exist, or one that does something different from what you asked. Test it in Packet Tracer, or a lab, first.

## Check yourself

> [!question]- What is the difference between AI and machine learning?
> AI is any software that does tasks that normally need human thinking. Machine learning is a kind of AI that learns patterns from data instead of following rules a person wrote.

> [!question]- What is the difference between generative and predictive AI?
> Generative AI makes new content, such as text or configuration, from a request. Predictive AI uses past data to say what will probably happen next.

> [!question]- Name three ways machine learning helps run a network.
> It finds unusual traffic that might be an attack, predicts devices or links that are about to fail, and links many alarms together to find the real cause.

> [!question]- Why must you check a configuration suggested by generative AI?
> Generative AI can be wrong while sounding sure, and can invent commands, so a suggestion must be checked and tested before it goes on a real device.
