# 1.04 Subnetting

> [!abstract] Why this matters
> Subnetting means splitting one network into smaller networks. The exam has many subnetting questions, and you only get about one minute for each. With the method below and daily practice, you can do one in under 30 seconds, with no binary.

## An example first

You have `192.168.10.0/24`. You need four networks.

1. Four networks need 2 extra network bits, because 2 × 2 = 4.
2. So the new prefix is /24 + 2 = **/26**.
3. A /26 mask is `255.255.255.192`.
4. The **block size** is 256 − 192 = **64**. Each new network is 64 addresses long.
5. The networks start at 0, 64, 128 and 192.

| Network | First host | Last host | Broadcast |
|---|---|---|---|
| 192.168.10.0/26 | .1 | .62 | .63 |
| 192.168.10.64/26 | .65 | .126 | .127 |
| 192.168.10.128/26 | .129 | .190 | .191 |
| 192.168.10.192/26 | .193 | .254 | .255 |

Each has 64 − 2 = 62 usable hosts.

## The magic number method

The block size is also called the **magic number**.

1. Find the **interesting octet**. That's the octet where the mask isn't 255 or 0.
2. Magic number = 256 − the mask value in that octet.
3. The networks start at every multiple of the magic number in that octet.
4. The broadcast is one less than the next network.

### Which network is 172.16.45.200/20 in?

1. A /20 mask is `255.255.240.0`. The interesting octet is the third one, which is 240.
2. Magic number = 256 − 240 = **16**.
3. Multiples of 16 in the third octet: 0, 16, 32, **48**. The address has 45, which is between 32 and 48. So it's in the 32 block.
4. Network: `172.16.32.0`. Next network: `172.16.48.0`. Broadcast: `172.16.47.255`.
5. Usable hosts: `172.16.32.1` to `172.16.47.254`.

## The table to learn by heart

| Prefix | Mask | Magic number | Usable hosts |
|---|---|---|---|
| /24 | 255.255.255.0 | 256 | 254 |
| /25 | 255.255.255.128 | 128 | 126 |
| /26 | 255.255.255.192 | 64 | 62 |
| /27 | 255.255.255.224 | 32 | 30 |
| /28 | 255.255.255.240 | 16 | 14 |
| /29 | 255.255.255.248 | 8 | 6 |
| /30 | 255.255.255.252 | 4 | 2 |
| /31 | 255.255.255.254 | 2 | 2, only for point-to-point links |
| /32 | 255.255.255.255 | 1 | 1, a single host |

The same pattern repeats in the third octet: /16 to /23, and in the second octet: /8 to /15.

## Choosing a mask for a number of hosts

"I need 50 hosts." Find the smallest number of host bits where 2 to that power, minus 2, is at least 50.

- 2⁵ − 2 = 30. That's too small.
- 2⁶ − 2 = 62. That's enough.
- 6 host bits means 32 − 6 = **/26**.

## VLSM

VLSM means variable-length subnet masks. It gives each network a mask that fits its size, so you waste fewer addresses.

The rule: **give out the biggest networks first.**

You have `10.0.0.0/24`. You need: Sales with 100 hosts, IT with 50, Office with 20, and a router link with 2.

| Need | Prefix | Network | Range | Broadcast |
|---|---|---|---|---|
| Sales, 100 hosts | /25 | 10.0.0.0 | .1 to .126 | .127 |
| IT, 50 hosts | /26 | 10.0.0.128 | .129 to .190 | .191 |
| Office, 20 hosts | /27 | 10.0.0.192 | .193 to .222 | .223 |
| Router link, 2 hosts | /30 | 10.0.0.224 | .225 to .226 | .227 |

## Lab: build the VLSM plan

1. Build a 2911 router with three switches: Sales, IT and Office. Connect them to G0/0, G0/1 and G0/2. Put one PC on each switch.
2. Give each router interface the **first usable** address of its network from the table. For example, G0/0 gets `10.0.0.1 255.255.255.128`.
3. Give each PC the **last usable** address of its network, the right mask, and the router's address as its gateway.
4. Ping from the Sales PC to the Office PC. It should work, because the router joins the networks.
5. Type `show ip route` on the router. You should see three **C** lines, one for each connected network.
6. Get the practice going: [[Cheat Sheet - Subnetting]] has drills. Do five every day.

> [!sith] The dark side
> Giving out the small networks first in VLSM. If you place the /30 at 10.0.0.0 first, the /25 for Sales can't start until 10.0.0.128, and later networks no longer fit. Biggest first, always.

## Check yourself

> [!question]- What is the mask, magic number and number of usable hosts for a /27?
> A /27 has the mask 255.255.255.224, a magic number of 32, and 30 usable hosts.

> [!question]- Which network and broadcast address does 192.168.5.77/28 belong to?
> The magic number for a /28 is 16. 77 falls between 64 and 80, so the network is 192.168.5.64 and the broadcast is 192.168.5.79.

> [!question]- What is the smallest prefix that gives at least 50 usable hosts?
> A /26, because 6 host bits give 2 to the power of 6, minus 2, which is 62 usable hosts.

> [!question]- What is the network and broadcast address of 172.16.45.200/20?
> The network is 172.16.32.0 and the broadcast is 172.16.47.255, because the magic number is 16 in the third octet and 45 falls in the block from 32 to 47.

> [!question]- Which prefix is normally used on a point-to-point link between two routers?
> A /30, which gives exactly two usable addresses. A /31 also works on point-to-point links.

> [!question]- What is the rule for giving out networks with VLSM?
> Give out the biggest networks first, then the smaller ones, so every network starts on a correct boundary and nothing overlaps.

> [!question]- How many /26 networks fit into one /24?
> Four, because a /26 borrows 2 bits from the host part, and 2 to the power of 2 is 4.
