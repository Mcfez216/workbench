# 1.05 IPv6 Addressing

> [!abstract] Why this matters
> The world ran out of new IPv4 addresses. IPv6 has so many addresses that every device can have its own. The exam expects you to shorten IPv6 addresses, know the address types, and set IPv6 up on a router.

## An example first

`2001:0db8:0000:0000:0000:0a00:0000:0001`

1. Drop the zeros at the front of each group: `2001:db8:0:0:0:a00:0:1`
2. Replace **one** run of all-zero groups with `::` → `2001:db8::a00:0:1`

That's the shortest correct form.

## The rules

- An IPv6 address is **128 bits**. It's written as 8 groups of 4 hex digits. Hex, or hexadecimal, counts 0 to 9 then a to f.
- You can drop leading zeros in any group.
- You can use `::` **only once** in an address. If you used it twice, nobody could tell how many zeros each one stood for.
- If there are two runs of zeros the same length, shorten the first one.
- The prefix is written the same way as IPv4. A normal network is a **/64**. The first 64 bits are the network, and the last 64 bits are the **interface ID**. The interface ID is the host part.

## The address types

| Type | Starts with | What it's for |
|---|---|---|
| Global unicast | 2000::/3, so 2 or 3 | Public addresses, used on the internet |
| Unique local | FC00::/7, in practice FD | Private addresses, like 10.0.0.0 in IPv4 |
| Link-local | FE80::/10 | Only on one link. Every IPv6 interface has one. Routers use them as next hops. |
| Multicast | FF00::/8 | A group of devices. IPv6 has no broadcast. |
| Loopback | ::1/128 | This device |
| Unspecified | ::/128 | No address yet |

Multicast groups to know: `FF02::1` is all nodes. `FF02::2` is all routers.

## Anycast

An **anycast** address is the same address given to several devices. Traffic goes to the nearest one. It's set up like a normal address.

## EUI-64

EUI-64 is a way for a device to make its own interface ID from its MAC address.

MAC address `00:1A:2B:3C:4D:5E`:

1. Split it in half: `001A2B` and `3C4D5E`.
2. Put `FFFE` in the middle: `001A2BFFFE3C4D5E`.
3. Flip the 7th bit of the first byte. `00` is `00000000` in binary. Flipping the 7th bit gives `00000010`, which is `02`.
4. The interface ID is `021A:2BFF:FE3C:4D5E`.

## How devices get addresses

- **Static.** You type it in.
- **SLAAC.** Stateless address autoconfiguration. The router announces the network prefix in a **Router Advertisement**, or RA. The device adds its own interface ID.
- **DHCPv6.** A server gives out addresses, like DHCP in IPv4.

IPv6 uses **NDP**, the Neighbor Discovery Protocol, instead of ARP. Neighbor Solicitation and Neighbor Advertisement messages find MAC addresses. Router Solicitation and Router Advertisement messages find routers.

## The commands

```text
ipv6 unicast-routing
interface g0/0
 ipv6 address 2001:db8:acad:1::1/64
 ipv6 address fe80::1 link-local
 no shutdown
interface g0/1
 ipv6 address 2001:db8:acad:2::/64 eui-64
 no shutdown
 end
show ipv6 interface brief
```

`ipv6 unicast-routing` turns on IPv6 routing. Without it, the router won't send Router Advertisements or forward IPv6 packets.

## Lab

1. Build a 2911 router with a switch and a PC on G0/0, and another switch and PC on G0/1.
2. Type the commands above on the router.
3. On PC0, go to Desktop → IP Configuration. In the IPv6 part, choose **Automatic**. It should get an address starting `2001:db8:acad:1:` from SLAAC.
4. Do the same on PC1. It gets an address starting `2001:db8:acad:2:`.
5. In `show ipv6 interface brief`, find the EUI-64 address on G0/1. Check it against the router's MAC address with `show interfaces g0/1`.
6. Ping PC1's IPv6 address from PC0. It should work.

> [!sith] The dark side
> Using `::` twice. `2001::1::5` is not a valid address, because you can't tell where the zeros go. If you see it in an exam answer, that answer is wrong.

## Check yourself

> [!question]- How many bits is an IPv6 address?
> An IPv6 address is 128 bits long.

> [!question]- What is the shortest form of 2001:0db8:0000:0000:0000:0000:0000:0001?
> 2001:db8::1

> [!question]- Why can :: only appear once in an IPv6 address?
> If :: appeared twice, there would be no way to know how many zero groups each one replaced.

> [!question]- What prefix does a link-local IPv6 address start with?
> A link-local address starts with FE80::/10. Every IPv6 interface has one, and it only works on its own link.

> [!question]- What do global unicast and unique local IPv6 addresses start with?
> Global unicast addresses start with 2000::/3, so they begin with 2 or 3. Unique local addresses start with FC00::/7, and in practice begin with FD.

> [!question]- How does EUI-64 make an interface ID from a MAC address?
> It splits the MAC address in half, puts FFFE in the middle, and flips the 7th bit of the first byte.

> [!question]- What does SLAAC do?
> SLAAC lets a device give itself an IPv6 address. It takes the network prefix from the router's Router Advertisement and adds its own interface ID.

> [!question]- What replaces ARP in IPv6?
> NDP, the Neighbor Discovery Protocol, replaces ARP. It uses Neighbor Solicitation and Neighbor Advertisement messages to find MAC addresses.
