# 1.01 The OSI and TCP-IP Models

> [!abstract] Why this matters
> A model splits networking into layers. Each layer has one job. When something breaks, the layers tell you where to look. Engineers say "it's a Layer 2 problem", and you need to know what that means.

## An example first

You open a web page.

1. Your browser asks for the page. That's the **application** layer.
2. TCP cuts the request into pieces and numbers them. That's the **transport** layer.
3. IP puts the address of the web server on each piece. That's the **network** layer.
4. Ethernet puts the MAC address of the next device on it. A MAC address is the fixed address of one network card. That's the **data link** layer.
5. The card sends it as electrical signals down the cable. That's the **physical** layer.

At the other end, each layer removes its own part, in the opposite order.

## The OSI model

| Layer | Name | What it does | Data is called | Example |
|---|---|---|---|---|
| 7 | Application | Talks to the program | Data | HTTP, DNS |
| 6 | Presentation | Formats and encrypts data | Data | TLS, JPEG |
| 5 | Session | Starts and ends conversations | Data | |
| 4 | Transport | Splits data up, uses port numbers | Segment | TCP, UDP |
| 3 | Network | Logical addresses and routing | Packet | IPv4, IPv6 |
| 2 | Data link | MAC addresses on one network | Frame | Ethernet, 802.11 |
| 1 | Physical | Bits on a cable or radio | Bits | Cables, signals |

A way to remember layers 1 to 7: **P**lease **D**o **N**ot **T**hrow **S**ausage **P**izza **A**way.

## The TCP/IP model

The internet really uses the TCP/IP model. It joins some OSI layers together.

| TCP/IP layer | OSI layers |
|---|---|
| Application | 5, 6 and 7 |
| Transport | 4 |
| Internet | 3 |
| Network access (also called link) | 1 and 2 |

## Encapsulation

Each layer adds a **header** to the data. A header is a small block of information at the front, like an address on an envelope. Adding headers on the way down is called **encapsulation**. Removing them on the way up is called **de-encapsulation**.

## Which device works at which layer

- A **hub** works at Layer 1. It copies bits out of every port.
- A **switch** works at Layer 2. It reads MAC addresses.
- A **router** works at Layer 3. It reads IP addresses.

## Lab

1. Open your lab `0.2 Tour.pkt`, or build two PCs and a switch again.
2. Switch to **Simulation** mode.
3. Ping from PC0 to PC1.
4. Click the first envelope in the Event List. The **OSI Model** tab shows each layer, from Layer 1 up.
5. Open the **Outbound PDU Details** tab. A PDU, or protocol data unit, is the data at one layer. Find the Ethernet header, with its source and destination MAC addresses. Find the IP header, with its source and destination IP addresses.

> [!sith] The dark side
> Mixing up the names of the data at each layer. A segment is Layer 4, a packet is Layer 3 and a frame is Layer 2. The exam uses these words exactly. "Switches forward frames" and "routers forward packets" are both correct. Swapping them is wrong.

## Check yourself

> [!question]- What are the seven layers of the OSI model, from Layer 1 to Layer 7?
> Physical, data link, network, transport, session, presentation, application.

> [!question]- What are the four layers of the TCP/IP model?
> Application, transport, internet, and network access, which is also called link.

> [!question]- What is the data called at Layers 2, 3 and 4?
> At Layer 2 it is a frame, at Layer 3 it is a packet, and at Layer 4 it is a segment for TCP or a datagram for UDP.

> [!question]- What is encapsulation?
> Encapsulation is when each layer adds its own header to the data on the way down the layers, before it is sent.

> [!question]- At which OSI layer do a hub, a switch and a router work?
> A hub works at Layer 1, a switch at Layer 2, and a router at Layer 3.
