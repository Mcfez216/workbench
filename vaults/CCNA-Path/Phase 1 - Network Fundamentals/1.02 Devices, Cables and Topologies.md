# 1.02 Devices, Cables and Topologies

> [!abstract] Why this matters
> The exam asks what each network device does, which cable to use, and how networks are laid out. In real work, half of all network problems are a bad cable or the wrong port.

## The devices

| Device | What it does |
|---|---|
| Router | Joins different networks and picks the best path between them. |
| Layer 2 switch | Joins devices in one network, and sends each frame only where it needs to go. |
| Layer 3 switch | A switch that can also route between VLANs. |
| Firewall | Allows or blocks traffic using rules. A next-generation firewall, or NGFW, also looks inside the traffic. |
| IPS | An intrusion prevention system. It spots attacks in traffic and stops them. |
| Access point | Joins wireless devices to the wired network. |
| Wireless LAN controller | Manages many access points from one place. |
| Endpoint | A device people use, like a PC, a phone or a printer. |
| Server | A computer that provides a service, like web pages or files. |
| PoE switch | A switch that also sends power down the cable. PoE means Power over Ethernet. It powers phones, cameras and access points. |

## Copper cables

- **UTP** means unshielded twisted pair. It's the normal network cable.
- Copper Ethernet reaches up to **100 metres**.
- Cat 5e carries 1 Gbps. Cat 6a carries 10 Gbps.

## Fibre cables

Fibre carries light, not electricity. It goes further and isn't affected by electrical noise.

| Type | Core | Light source | Distance | Cost |
|---|---|---|---|---|
| Single-mode | Very thin, 9 microns | Laser | Many kilometres | Higher |
| Multimode | Thicker, 50 or 62.5 microns | LED or cheap laser | Up to about 550 metres | Lower |

An **SFP** is a small removable module that plugs into a port. It lets one switch port use fibre or copper.

## Interface problems

`show interfaces` shows error counters. These are the ones to know.

- **Duplex mismatch.** Half duplex means one side talks at a time. Full duplex means both sides talk at once. If one end is half and the other is full, you see **late collisions** and slow traffic.
- **Speed mismatch.** If the speeds don't match, the link stays down.
- **CRC errors** and **input errors** usually mean a damaged cable or electrical noise.
- **Runts** are frames smaller than 64 bytes. **Giants** are frames bigger than 1518 bytes.

## Topologies

A topology is how the network is laid out.

- **Two-tier, or collapsed core.** Access switches connect users. Distribution switches join the access switches. The core and distribution layers are the same switches. Good for one building.
- **Three-tier.** Access, distribution and a separate core. The core moves traffic fast between distribution blocks. Good for a large campus.
- **Spine-leaf.** For data centres. Every leaf switch connects to every spine switch. Any server is always two hops from any other.
- **WAN.** A wide area network joins sites that are far apart.
- **SOHO.** Small office, home office. One box is usually the router, switch, firewall and access point.
- **On-premises and cloud.** On-premises means the equipment is in your own building. Cloud means someone else runs it, and you rent it.

## Lab

1. Build two 2960 switches. Connect their Fa0/24 ports with a **Copper Straight-Through** cable. Does the link come up? It does, because of Auto-MDIX.
2. Delete that cable, and connect them with **Copper Cross-Over**. This is the correct cable.
3. On switch 1, type:
   ```text
   enable
   configure terminal
   interface fa0/24
    duplex half
    speed 100
   ```
4. Ping across the link from a PC on each switch, many times.
5. Type `show interfaces fa0/24` on both switches. Look for collisions, and the duplex setting on each side.
6. Put it back with `duplex auto` and `speed auto`.

> [!sith] The dark side
> Setting speed and duplex by hand on one end only. When one end is set by hand, the other end can't agree with it. It usually falls back to half duplex. Set both ends by hand, or leave both on auto.

## Check yourself

> [!question]- What is the maximum length of a copper Ethernet cable?
> A copper Ethernet cable can be up to 100 metres long.

> [!question]- What is the difference between single-mode and multimode fibre?
> Single-mode fibre has a very thin core and uses a laser, so it reaches many kilometres but costs more. Multimode fibre has a thicker core and uses cheaper light sources, and reaches up to about 550 metres.

> [!question]- What symptom shows a duplex mismatch?
> A duplex mismatch causes late collisions and slow traffic on the half-duplex side of the link.

> [!question]- What is a spine-leaf topology, and where is it used?
> In a spine-leaf topology every leaf switch connects to every spine switch, so any two servers are always the same distance apart. It is used in data centres.

> [!question]- What does PoE do?
> PoE, or Power over Ethernet, lets a switch send electrical power down the network cable to devices like phones, cameras and access points.

> [!question]- What is the difference between a two-tier and a three-tier campus design?
> A two-tier design joins the core and distribution layers into one set of switches. A three-tier design has separate access, distribution and core layers, for larger networks.
