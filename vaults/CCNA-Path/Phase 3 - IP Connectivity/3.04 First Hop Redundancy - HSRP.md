# 3.04 First Hop Redundancy - HSRP

> [!abstract] Why this matters
> Every PC has one default gateway. If that router fails, the PCs are cut off, even if a second router is right there. A first hop redundancy protocol, or FHRP, lets two routers share one gateway address. If one fails, the other takes over, and the PCs don't notice.

## The idea

Two routers share a **virtual IP address** and a **virtual MAC address**. The PCs use the virtual IP as their gateway.

- One router is **active**. It answers for the virtual address and forwards the traffic.
- The other is **standby**. It watches the active router's Hello messages.
- If the Hellos stop, the standby router becomes active. It answers ARP for the same virtual MAC, so the PCs don't need to change anything.

## The three FHRPs

| | HSRP | VRRP | GLBP |
|---|---|---|---|
| Full name | Hot Standby Router Protocol | Virtual Router Redundancy Protocol | Gateway Load Balancing Protocol |
| Standard | Cisco only | Open standard | Cisco only |
| Roles | Active and standby | Master and backup | AVG and AVFs |
| Shares the load? | No, one router at a time | No | Yes, all routers forward |
| Virtual MAC | 0000.0c07.acXX in version 1 | 0000.5e00.01XX | 0007.b400.XXYY |

XX is the group number in hex.

## HSRP details

- The default **priority** is 100. The highest priority becomes active. If priorities tie, the highest IP address wins.
- **Preempt** lets a router with a higher priority take over when it comes back. It's **off** by default.
- Hellos go every **3 seconds**. The **hold time** is **10 seconds**.
- **HSRPv1** supports groups 0 to 255 and uses the multicast address 224.0.0.2.
- **HSRPv2** supports groups 0 to 4095, supports IPv6, and uses 224.0.0.102. Its virtual MAC is 0000.0c9f.fXXX.

## The commands

```text
R1(config)# interface g0/0
R1(config-if)# ip address 192.168.1.2 255.255.255.0
R1(config-if)# standby 1 ip 192.168.1.1
R1(config-if)# standby 1 priority 110
R1(config-if)# standby 1 preempt

R2(config)# interface g0/0
R2(config-if)# ip address 192.168.1.3 255.255.255.0
R2(config-if)# standby 1 ip 192.168.1.1
```

```text
show standby
show standby brief
```

## Lab

1. Build two 2911 routers, R1 and R2, and one 2960 switch. Connect both routers' G0/0 to the switch. Add two PCs to the switch.
2. Type the commands above. Check the router addresses are .2 and .3, and the virtual address is .1.
3. Give both PCs the gateway `192.168.1.1`.
4. Run `show standby brief` on both routers. R1 should be **Active** and R2 **Standby**.
5. Add a server behind both routers, on a second network, and route to it. Or simply ping `192.168.1.1` from a PC with `ping -t`.
6. Shut down R1's G0/0. One or two pings are lost, then they continue. R2 is now active.
7. Bring R1 back with `no shutdown`. Because of preempt and priority 110, R1 becomes active again.
8. On a PC, type `arp -a`. The gateway's MAC address is `0000.0c07.ac01`. That's the HSRP virtual MAC for group 1.

> [!sith] The dark side
> Forgetting `preempt`. R1 fails, R2 takes over, R1 comes back with a higher priority, and nothing happens. R2 stays active for ever. If you want the better router back in charge after a failure, turn on preempt.

## Check yourself

> [!question]- What does a first hop redundancy protocol do?
> It lets two or more routers share one virtual gateway IP address and MAC address, so PCs keep a working default gateway if one router fails.

> [!question]- What is the default HSRP priority, and which router becomes active?
> The default priority is 100. The router with the highest priority becomes active. If priorities are equal, the highest IP address wins.

> [!question]- What does HSRP preempt do?
> Preempt lets a router with a higher priority take back the active role when it comes back online. It is off by default.

> [!question]- What is the HSRP version 1 virtual MAC address for group 1?
> 0000.0c07.ac01.

> [!question]- Which FHRP is an open standard, and which one shares the load between routers?
> VRRP is the open standard. GLBP shares the load, because all its routers forward traffic.

> [!question]- What are the default HSRP hello and hold timers?
> The hello timer is 3 seconds and the hold timer is 10 seconds.
