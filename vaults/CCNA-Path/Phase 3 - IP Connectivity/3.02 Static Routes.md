# 3.02 Static Routes

> [!abstract] Why this matters
> A static route is a route you type in by hand. Small networks use them, and every network uses a default route to reach the internet. The exam asks you to write them for IPv4 and IPv6, including backup routes.

## An example first

```text
     10.1.1.0/24          10.0.12.0/30          10.2.2.0/24
PC1 ----- G0/0 [R1] G0/1 ---------- G0/1 [R2] G0/0 ----- PC2
                  .1               .2
```

R1 knows 10.1.1.0/24 and 10.0.12.0/30, because they're connected. It doesn't know 10.2.2.0/24. So you tell it:

```text
R1(config)# ip route 10.2.2.0 255.255.255.0 10.0.12.2
R2(config)# ip route 10.1.1.0 255.255.255.0 10.0.12.1
```

Routes must go **both ways**. R2 needs a route back, or the replies get lost.

## The ways to write one

```text
ip route 10.2.2.0 255.255.255.0 10.0.12.2
ip route 10.2.2.0 255.255.255.0 g0/1
ip route 10.2.2.0 255.255.255.0 g0/1 10.0.12.2
```

1. With a **next hop**: the address of the next router. This is the normal way.
2. With an **exit interface** only. This is called **directly attached**. Only use it on point-to-point links.
3. With **both**. This is called **fully specified**.

## Kinds of static route

- A **network route** goes to one network, like the example.
- A **host route** goes to one address, with a /32 mask: `ip route 10.2.2.50 255.255.255.255 10.0.12.2`.
- A **default route** matches everything: `ip route 0.0.0.0 0.0.0.0 203.0.113.1`.
- A **floating static route** is a backup. You give it a higher AD than the main route, so it's only used if the main one disappears.

```text
ip route 0.0.0.0 0.0.0.0 203.0.113.1
ip route 0.0.0.0 0.0.0.0 198.51.100.1 5
```

The `5` at the end is the AD. The first route, with AD 1, is used. If its link goes down, the second one takes over.

To back up an OSPF route, the floating route's AD must be higher than 110.

## IPv6 static routes

```text
ipv6 unicast-routing
ipv6 route 2001:db8:2::/64 2001:db8:12::2
ipv6 route ::/0 2001:db8:12::2
ipv6 route 2001:db8:2::/64 g0/1 fe80::2
```

If the next hop is a **link-local** address, you must also give the exit interface. A link-local address could be on any link, so the router needs to know which one.

## Lab

1. Build the network in the example with two 2911 routers. Use a cross-over cable between the G0/1 ports.
2. Set up all the addresses. Give each PC its router as the gateway.
3. Ping from PC1 to PC2. It fails.
4. Add the static route on R1 only. Ping again. It still fails, because R2 has no route back.
5. Add the static route on R2. Ping again. It works.
6. Run `show ip route` on both routers. Find the S lines.
7. Add a third router, R3, connected to both R1 and R2, as a backup path. Add floating routes through R3 with AD 5. Shut down R1's G0/1. Run `show ip route`. The backup route is now in the table. Ping PC2 again.
8. Add IPv6 to all the links and write IPv6 static routes so PC1 can ping PC2 over IPv6.

> [!sith] The dark side
> Adding a route in one direction only. The ping reaches PC2, but the reply has no way home, so it looks like nothing arrived. When a ping fails, check the route there **and** the route back.

## Check yourself

> [!question]- Write a static route on R1 to 192.168.50.0/24 through the next hop 10.0.0.2.
> ip route 192.168.50.0 255.255.255.0 10.0.0.2

> [!question]- Write an IPv4 default route through 203.0.113.1.
> ip route 0.0.0.0 0.0.0.0 203.0.113.1

> [!question]- What is a floating static route?
> A floating static route is a backup route with a higher administrative distance than the main route. It is only used when the main route disappears.

> [!question]- What AD must a floating static route have to back up an OSPF route?
> Its administrative distance must be higher than 110, which is the AD of OSPF.

> [!question]- What mask does a host route use?
> A host route uses a /32 mask, 255.255.255.255, so it matches exactly one address.

> [!question]- Why does an IPv6 static route to a link-local next hop also need an exit interface?
> A link-local address is only unique on its own link, so the router needs the exit interface to know which link the next hop is on.

> [!question]- Write an IPv6 default route through 2001:db8:12::2.
> ipv6 route ::/0 2001:db8:12::2
