# 3.01 The Routing Table

> [!abstract] Why this matters
> IP connectivity is the biggest part of the exam, a quarter of it. It all starts with reading a routing table. The exam shows you `show ip route` output and asks where a packet goes. You need to answer that quickly and correctly.

## An example first

```text
R1# show ip route
Gateway of last resort is 203.0.113.1 to network 0.0.0.0

S*    0.0.0.0/0 [1/0] via 203.0.113.1
      10.0.0.0/8 is variably subnetted   (some lines left out)
C        10.1.1.0/24 is directly connected, GigabitEthernet0/0
L        10.1.1.1/32 is directly connected, GigabitEthernet0/0
O        10.2.0.0/16 [110/2] via 10.0.12.2, 00:05:11, GigabitEthernet0/1
S        10.2.5.0/24 [1/0] via 10.0.13.3
```

A packet for `10.2.5.9` matches three routes: `0.0.0.0/0`, `10.2.0.0/16` and `10.2.5.0/24`. It goes to **10.0.13.3**. The next section says why.

## Rule 1: the longest match wins

The router picks the route with the **longest prefix** that matches. That's the most specific route. `/24` is longer than `/16`, which is longer than `/0`. This rule comes first, before anything else.

## Rule 2: the lowest administrative distance

If two **sources** offer a route to the **same** prefix, the router trusts the one with the lowest **administrative distance**, or AD. AD is how much a source is trusted. Lower is better.

| Source | AD |
|---|---|
| Connected | 0 |
| Static | 1 |
| eBGP | 20 |
| EIGRP | 90 |
| OSPF | 110 |
| RIP | 120 |
| External EIGRP | 170 |
| iBGP | 200 |
| Unusable | 255 |

## Rule 3: the lowest metric

If one protocol offers two paths to the same prefix, the lower **metric** wins. The metric is the protocol's own measure of distance. OSPF's metric is called **cost**. If metrics are equal, the router uses both. That's **ECMP**, equal-cost multi-path.

## Reading one line

`O 10.2.0.0/16 [110/2] via 10.0.12.2, 00:05:11, GigabitEthernet0/1`

| Part | Means |
|---|---|
| `O` | Learned from OSPF |
| `10.2.0.0/16` | The destination network |
| `[110/2]` | AD 110, metric 2 |
| `via 10.0.12.2` | The next hop, the next router to send to |
| `00:05:11` | Learned 5 minutes 11 seconds ago |
| `GigabitEthernet0/1` | The interface to send it out of |

## The route codes

| Code | Means |
|---|---|
| C | Connected network |
| L | Local. The router's own address, as a /32. |
| S | Static |
| S* | Static default route |
| O | OSPF |
| D | EIGRP |
| R | RIP |
| B | BGP |

## The default route

The **default route** is `0.0.0.0/0`. It matches every address, but with the shortest prefix possible, so it's only used when nothing else matches. It's also called the **gateway of last resort**.

## Lab

1. Open `1.04 Subnetting.pkt`, or any lab with a router and several networks.
2. Run `show ip route`. Find every C line and its L line. Check each L is the router's own address.
3. Run `show ip route 10.0.0.130`. The router tells you which route it would use for that one address.
4. Write down three addresses. For each one, decide which route it matches, before you check with `show ip route <address>`.

> [!sith] The dark side
> Choosing a route by its AD before checking prefix length. A static route to `10.0.0.0/8`, with AD 1, loses to an OSPF route to `10.1.0.0/16`, with AD 110, for the address `10.1.2.3`. The longest match always comes first. AD only matters between routes to exactly the same prefix.

## Check yourself

> [!question]- How does a router choose between routes to 10.0.0.0/8 and 10.1.0.0/16 for the address 10.1.2.3?
> It uses the longest prefix match, so it picks 10.1.0.0/16, because /16 is more specific than /8.

> [!question]- What is administrative distance?
> Administrative distance is how much a router trusts the source of a route. When two sources offer the same prefix, the lower administrative distance wins.

> [!question]- What is the administrative distance of connected, static, EIGRP, OSPF and RIP routes?
> Connected is 0, static is 1, EIGRP is 90, OSPF is 110 and RIP is 120.

> [!question]- In the route O 10.2.0.0/16 [110/2], what do 110 and 2 mean?
> 110 is the administrative distance, which shows it came from OSPF, and 2 is the OSPF cost, which is the metric.

> [!question]- What is the gateway of last resort?
> The gateway of last resort is the next hop of the default route, 0.0.0.0/0, which the router uses when no other route matches.

> [!question]- What does the L code mean in a routing table?
> L means a local route, the router's own interface address as a /32.
