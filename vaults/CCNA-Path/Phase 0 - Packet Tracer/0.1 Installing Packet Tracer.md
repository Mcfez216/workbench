# 0.1 Installing Packet Tracer

> [!abstract] Why this matters
> Cisco Packet Tracer is a free network simulator. It gives you routers, switches and PCs on your screen that behave like real ones. You can practise every lab in this vault without buying any equipment.

## Where to get it

Packet Tracer comes from Cisco Networking Academy. You need a free account to download it.

1. Go to netacad.com and make a free account.
2. Enrol in the free course **Getting Started with Cisco Packet Tracer**. The download link is inside it.
3. Download the latest version for your system: Windows, macOS or Ubuntu.
4. Install it, then open it.
5. Sign in with the same Networking Academy account. You should see an empty white workspace.

> [!tip] On Ubuntu
> The download is a .deb file. Install it with `sudo apt install ./CiscoPacketTracer_*.deb`. The `./` matters. It tells apt the file is in this folder.

## Where to keep your labs

A lab you save in Packet Tracer is a .pkt file.

1. Make a folder called `CCNA Labs` in your Documents folder.
2. Save each lab there, named after its note. For example, `1.04 Subnetting.pkt`.
3. Old labs are useful. You'll open them again to practise fixing things.

## Lab

1. Open Packet Tracer.
2. Click **File → Save As**, and save the empty workspace as `0.1 Test.pkt` in your `CCNA Labs` folder.
3. Close Packet Tracer and open the file again. It should open with no errors.

> [!sith] The dark side
> Packet Tracer files from a newer version often won't open in an older one. Keep one version on all your computers. If you share labs with a study partner, check you both have the same version.
