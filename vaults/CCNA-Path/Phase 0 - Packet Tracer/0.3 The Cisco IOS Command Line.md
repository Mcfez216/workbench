# 0.3 The Cisco IOS Command Line

> [!abstract] Why this matters
> Cisco routers and switches run an operating system called IOS. You set them up by typing commands. The exam has labs where you must type real commands, so you need to move around IOS without thinking about it.

## The modes

IOS has modes. Each mode lets you do different things. The prompt tells you which mode you're in.

| Mode | Prompt | How to get there | What it's for |
|---|---|---|---|
| User EXEC | `Router>` | You start here | Looking at a few things |
| Privileged EXEC | `Router#` | `enable` | Every `show` command, saving, restarting |
| Global configuration | `Router(config)#` | `configure terminal` | Settings for the whole device |
| Interface configuration | `Router(config-if)#` | `interface g0/0` | Settings for one port |
| Line configuration | `Router(config-line)#` | `line console 0` | Settings for logins |

`exit` goes back one mode. `end`, or Ctrl+Z, goes straight back to privileged EXEC.

## Your first configuration

```text
enable
configure terminal
hostname R1
interface g0/0
 ip address 192.168.1.1 255.255.255.0
 description LAN for the PCs
 no shutdown
 end
show ip interface brief
copy running-config startup-config
```

- `hostname R1` names the device. The prompt changes to `R1(config)#`.
- `no shutdown` turns the port on. Router ports start turned off. Switch ports start turned on.
- `no` in front of a command undoes it.

## Two configurations

- The **running-config** is the configuration the device is using right now. It's kept in RAM, so it's lost when the power goes off.
- The **startup-config** is saved in NVRAM. NVRAM is memory that keeps its contents with no power. The device loads it when it starts.
- `copy running-config startup-config` saves your work. `write memory`, or just `wr`, does the same thing.

## Shortcuts that save time

- **Short commands.** `conf t` means `configure terminal`. `sh ip int br` means `show ip interface brief`. Any short form works if only one command starts with it.
- **Tab** finishes a word for you.
- **?** lists what you can type next. Try `show ?`.
- **Up arrow** brings back the last command.
- **do** runs a privileged command from config mode. For example, `do show ip interface brief`.

## Lab

1. Put a **2911** router in the workspace. Click it, and open the **CLI** tab.
2. When asked "Would you like to enter the initial configuration dialog?", type `no`.
3. Type the commands from the example above.
4. In the `show ip interface brief` output, find G0/0. Status should be "up" only if a cable is plugged in. With no cable, it shows "down".
5. Connect a PC to G0/0 with a **Copper Cross-Over** cable. A PC and a router are both hosts, so the cross-over cable is correct.
6. Give the PC `192.168.1.10`, mask `255.255.255.0`, default gateway `192.168.1.1`.
7. Ping `192.168.1.1` from the PC. You should get replies.
8. On the router, type `reload` to restart it. Answer `no` if it asks to save. Is the hostname still R1?

> [!sith] The dark side
> Forgetting to save. You configure everything, the device restarts, and it's all gone. Type `copy running-config startup-config` whenever you finish a working step. In Packet Tracer, saving the .pkt file saves the running-config too, but on a real device it doesn't.

## Check yourself

> [!question]- What is the difference between the running-config and the startup-config?
> The running-config is the configuration in use right now, kept in RAM, and lost when the power goes off. The startup-config is saved in NVRAM, and the device loads it every time it starts.

> [!question]- How do you get from user EXEC mode to interface configuration mode for G0/0?
> Type enable to reach privileged EXEC mode, then configure terminal to reach global configuration mode, then interface g0/0.

> [!question]- Why must you type no shutdown on a router interface?
> Router interfaces start shut down, which means turned off. no shutdown turns the interface on. Switch ports start turned on.

> [!question]- What does the do command do in configuration mode?
> do lets you run a privileged EXEC command, like show ip interface brief, without leaving configuration mode.
