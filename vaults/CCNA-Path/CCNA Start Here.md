# CCNA Start Here

> [!abstract] Why this matters
> The CCNA is Cisco's entry certificate for network engineers. The exam is called 200-301. It checks that you can build, fix and protect a small network. This vault teaches every exam topic, and you practise each one in Cisco Packet Tracer.

> [!holocron] How this vault works
> Every note has the same parts, in the same order, so you always know where to look.
> 1. **Why this matters** is at the top.
> 2. Then the idea, in short sections.
> 3. Then the commands, in a grey box. Click **Copy** to copy them.
> 4. **Lab** tells you what to build in Packet Tracer, in numbered steps, and what you should see.
> 5. **The dark side** shows one common mistake.
> 6. **Check yourself** has questions. Click one to see the answer. They also become flashcards in Revise (Ctrl+Shift+V).
> 7. A link to the next note.
>
> A note takes 15 to 40 minutes, most of it in the lab. You don't have to finish a phase in one go.

## Your path

The phases follow the six parts of the exam. The percentage is how much of the exam each part is worth.

| Phase | What you'll be able to do | Exam | Rank |
|---|---|---|---|
| [[0.1 Installing Packet Tracer\|Phase 0: Packet Tracer]] | Build a network in Packet Tracer and type commands into a device | | Cable Runner |
| [[1.01 The OSI and TCP-IP Models\|Phase 1: Network Fundamentals]] | Address a network, subnet it, and explain how data moves | 20% | Cable Runner |
| [[2.01 VLANs\|Phase 2: Network Access]] | Set up switches: VLANs, trunks, spanning tree, EtherChannel, wireless | 20% | Switch Tech |
| [[3.01 The Routing Table\|Phase 3: IP Connectivity]] | Route between networks with static routes and OSPF | 25% | Router Tech |
| [[4.01 DHCP\|Phase 4: IP Services]] | Run DHCP, NAT, NTP, syslog and SSH | 10% | Network Tech |
| [[5.01 Securing Device Access\|Phase 5: Security Fundamentals]] | Lock down devices and ports, and filter traffic with ACLs | 15% | Network Tech |
| [[6.01 SDN and Controllers\|Phase 6: Automation and Programmability]] | Explain controllers, REST APIs, JSON and Ansible | 10% | Network Engineer |
| [[Labs/Capstone Labs\|Capstone labs]] | Build whole networks from a short brief, with no steps given | | |

Each phase ends with a short check called a gate: [[CCNA Phase Gates]].

## Your first hour

1. Read [[0.1 Installing Packet Tracer]] and install it.
2. Read [[0.2 The Packet Tracer Tour]] and build the two-PC network.
3. Read [[0.3 The Cisco IOS Command Line]].
4. Write one line in [[CCNA Done Log]].

## A daily habit

30 to 60 minutes a day is plenty. Labs take longer than reading, and that's fine.

1. **Start** with Learn → Where was I?
2. **Revise** for 10 minutes with Ctrl+Shift+V. Subnetting and the flashcards both get faster with daily practice.
3. **Do** one note and its lab.
4. **Save** the lab as a .pkt file, named after the note.
5. **Finish** by writing one line in [[CCNA Done Log]].

> [!tip] Stuck in a lab?
> Work from the bottom up. Is the cable connected, and are both lights green? Is the interface up? Is the IP address right? Is there a route? The note [[3.05 Troubleshooting Method]] walks through this in order.
