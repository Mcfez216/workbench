# 4.01 DHCP

> [!abstract] Why this matters
> Typing an address into every PC by hand doesn't work for hundreds of devices. DHCP hands out addresses, masks, gateways and DNS servers automatically. A Cisco router can be the DHCP server, and the exam expects you to set one up and fix it.

## How DHCP works: DORA

DHCP means Dynamic Host Configuration Protocol. A new PC gets an address in four messages.

1. **Discover.** The PC broadcasts: "Is there a DHCP server?"
2. **Offer.** The server replies with an address it can give.
3. **Request.** The PC broadcasts: "I'll take that address."
4. **Acknowledge.** The server confirms. The PC can now use it.

The first letters spell **DORA**. The address is given for a set time called the **lease**.

DHCP uses UDP. The server listens on port **67**. The client uses port **68**.

## The commands: a router as the DHCP server

```text
ip dhcp excluded-address 192.168.10.1 192.168.10.10
ip dhcp pool VLAN10
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 8.8.8.8
 domain-name lab.local
 lease 7
```

- `excluded-address` keeps some addresses out of the pool, for routers, servers and printers with fixed addresses.
- `default-router` is the gateway the PCs will use.
- `lease 7` is seven days.

```text
show ip dhcp binding
show ip dhcp pool
show ip dhcp conflict
```

## DHCP relay

DHCP Discover is a **broadcast**, and routers don't pass on broadcasts. So if the DHCP server is on another network, the gateway must **relay** the request. It turns the broadcast into a unicast and sends it to the server.

```text
interface g0/0.20
 ip helper-address 10.0.0.50
```

Put `ip helper-address` on the interface that faces the **PCs**, not the one facing the server.

## A router as a DHCP client

A router's internet port often gets its address from the internet provider:

```text
interface g0/1
 ip address dhcp
```

## On the PC

- Windows: `ipconfig /all` shows the lease. `ipconfig /release` and `ipconfig /renew` get a new one.
- In Packet Tracer: Desktop → IP Configuration → DHCP.

## Lab

1. Open `2.03 ROAS.pkt`. It has VLAN 10 and VLAN 20 on subinterfaces.
2. On the router, create a pool for each VLAN, with `excluded-address` for .1 to .10 in each.
3. Set every PC to **DHCP**. Each should get an address in its own VLAN, with the right gateway.
4. Run `show ip dhcp binding`. You should see each PC's MAC address and the address it got.
5. Now move the DHCP service to a server. Create VLAN 30 on the switch, and add the subinterface `g0/0.30` with `encapsulation dot1Q 30` and `192.168.30.1/24` on the router. Add a **Server-PT** in VLAN 30 at `192.168.30.50`, gateway `192.168.30.1`. In its **Services → DHCP**, create a pool for VLAN 10 and another for VLAN 20. In Packet Tracer, a pool on a server is matched to the network by its default gateway.
6. Remove the router's pools with `no ip dhcp pool VLAN10` and `no ip dhcp pool VLAN20`.
7. On the PCs, click DHCP again. They fail and get 169.254 addresses.
8. Add `ip helper-address 192.168.30.50` to the VLAN 10 and VLAN 20 subinterfaces. Try again. They get addresses now.
9. Watch the four DORA messages in **Simulation** mode, filtered to DHCP.

> [!sith] The dark side
> Forgetting `ip helper-address` when the DHCP server is on another network. The PC's Discover never leaves its own VLAN, so it never gets an answer, and the PC gives itself a 169.254 address. If DHCP works in one VLAN but not another, check the helper address on that VLAN's gateway.

## Check yourself

> [!question]- What are the four DHCP messages, in order?
> Discover, Offer, Request and Acknowledge, which spell DORA.

> [!question]- Which UDP ports does DHCP use?
> The DHCP server uses UDP port 67 and the client uses UDP port 68.

> [!question]- Why does a router need ip helper-address when the DHCP server is on another network?
> A DHCP Discover is a broadcast, and routers don't forward broadcasts. ip helper-address makes the router relay the request to the server as a unicast.

> [!question]- On which interface do you put ip helper-address?
> On the interface that faces the clients, which is their default gateway, not the interface that faces the server.

> [!question]- What does ip dhcp excluded-address do?
> It stops the DHCP server handing out certain addresses, so they can be used for fixed devices like routers, servers and printers.

> [!question]- Which command shows the addresses a Cisco DHCP server has handed out?
> show ip dhcp binding.

> [!question]- Which command makes a router interface get its address from DHCP?
> ip address dhcp, typed on that interface.
