# 4.06 FTP and TFTP

> [!abstract] Why this matters
> Engineers copy files to and from network devices all the time: configuration backups and new IOS versions. FTP and TFTP are the two usual ways. The exam asks how they differ.

## Side by side

| | FTP | TFTP |
|---|---|---|
| Full name | File Transfer Protocol | Trivial File Transfer Protocol |
| Transport | TCP | UDP |
| Ports | 21 for control, 20 for data | 69 |
| Login | Username and password | None |
| List folders? | Yes | No. You must know the file name. |
| Encrypted? | No | No |

- FTP uses **two** connections. One sends commands. The other carries the file.
- TFTP is very simple. It's good for a quick copy on a trusted network.
- For safe copies, use **SFTP** or **SCP**, which run over SSH.

## The commands

```text
copy running-config tftp:
copy tftp: running-config
copy flash: tftp:
show flash:
```

The router asks for the server's address and the file name.

To use FTP, tell the router the username and password first:

```text
ip ftp username admin
ip ftp password Cisco-Lab-1
copy running-config ftp:
```

## Upgrading IOS

1. Copy the new IOS file to flash: `copy tftp: flash:`.
2. Check it's there with `show flash:`.
3. Tell the router to boot it: `boot system flash:<file name>`.
4. Save, and `reload`.

## Lab

1. Build a router and a **Server-PT** at `10.0.0.100`. Check **Services → TFTP** is on.
2. On the router, type `copy running-config tftp:`. Give the server's address and the name `R1-backup.txt`.
3. On the server, look in **Services → TFTP**. Your file is in the list.
4. Change the hostname on the router. Then copy the backup back with `copy tftp: running-config`. The old hostname returns.
5. Turn on **Services → FTP** on the server. Add a user. Do the same backup with FTP.

> [!sith] The dark side
> Using TFTP across an untrusted network. There's no login and no encryption, so anyone could read your configuration, with its password hashes and SNMP strings. Use TFTP only on a trusted management network, and SCP or SFTP elsewhere.

## Check yourself

> [!question]- What is the difference between FTP and TFTP?
> FTP uses TCP ports 20 and 21, needs a username and password, and can list folders. TFTP uses UDP port 69, has no login, and can only send or fetch a file by name.

> [!question]- Which command backs up the running configuration to a TFTP server?
> copy running-config tftp:

> [!question]- Why does FTP use two ports?
> FTP uses one connection for commands, on TCP port 21, and a separate connection for the file data, on TCP port 20.

> [!question]- What is a safe way to copy files to a router?
> Use SCP or SFTP, which run over SSH and encrypt the transfer.
