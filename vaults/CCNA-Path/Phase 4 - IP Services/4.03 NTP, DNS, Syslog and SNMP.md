# 4.03 NTP, DNS, Syslog and SNMP

> [!abstract] Why this matters
> These four services keep a network running smoothly. NTP keeps the clocks right. DNS turns names into addresses. Syslog collects messages from every device. SNMP lets a monitoring system watch them. When something breaks at 3 a.m., these are how you find out what happened.

## NTP: the right time

NTP means Network Time Protocol. It uses **UDP 123**.

Correct time matters. Log messages from different devices only line up if their clocks match. Security certificates also fail with the wrong time.

- The **stratum** says how far a clock is from a perfect source. Stratum 0 is an atomic clock or GPS. Stratum 1 is a server connected straight to one. Each step further adds 1. Lower is better.
- A Cisco device can be an NTP **client**, and also a **server** for other devices.

```text
ntp server 10.0.0.1
clock timezone GMT 0
show ntp status
show ntp associations
show clock
```

To make a router an NTP server for others, using its own clock: `ntp master 3`. The 3 is its stratum.

## DNS: names to addresses

DNS means Domain Name System. It uses **UDP 53**, and TCP 53 for large replies.

- An **A record** maps a name to an IPv4 address.
- An **AAAA record** maps a name to an IPv6 address.
- A **CNAME** is another name for a name.
- An **MX record** names the mail server for a domain.

```text
ip domain-lookup
ip name-server 8.8.8.8
```

When you type a wrong command on a router, it thinks it's a name and tries to look it up. Stop that with `no ip domain-lookup`.

On a PC, `nslookup www.example.com` asks DNS directly.

## Syslog: the device's diary

Syslog collects log messages. It uses **UDP 514**. Every message has a **severity level** from 0 to 7. Lower is more serious.

| Level | Name | Example |
|---|---|---|
| 0 | Emergency | The device can't be used |
| 1 | Alert | Act at once |
| 2 | Critical | A critical problem |
| 3 | Error | An error happened |
| 4 | Warning | Something could go wrong |
| 5 | Notification | Normal but important. An interface went up or down. |
| 6 | Informational | Normal information |
| 7 | Debugging | Output from debug commands |

To remember the order: **E**very **A**wesome **C**isco **E**ngineer **W**ill **N**eed **I**ce cream **D**aily.

Choosing a level means "this level and everything more serious". So `logging trap warnings` sends levels 0 to 4.

```text
logging host 10.0.0.60
logging trap informational
service timestamps log datetime msec
show logging
```

`logging console` shows messages on the console. `logging buffered` keeps them in memory.

## SNMP: watching devices

SNMP means Simple Network Management Protocol. It uses **UDP 161** for questions and **UDP 162** for traps.

- The **NMS**, network management station, is the monitoring system.
- The **agent** runs on each device.
- The **MIB**, management information base, is the list of values the agent can report. Each value has an **OID**, object identifier.
- **Get** asks for a value. **Set** changes one. A **trap** is a message the device sends by itself, without being asked. An **inform** is a trap that must be acknowledged.

| Version | Security |
|---|---|
| SNMPv1 and v2c | A **community string**, which is a plain-text password. Weak. |
| SNMPv3 | Usernames, with authentication and encryption. Use this. |

```text
snmp-server community LAB-RO ro
snmp-server host 10.0.0.60 version 2c LAB-RO
```

## Lab

1. Open any lab with a router and a server, or build one: R1 with a server at `10.0.0.60` on G0/0.
2. On the server, open **Services**. Turn on **NTP**, and turn on **SYSLOG**.
3. On R1, type `ntp server 10.0.0.60`. Wait a minute. Run `show ntp status`. It should say "Clock is synchronized".
4. Type `service timestamps log datetime msec` and `logging host 10.0.0.60`.
5. Shut down and bring up an interface on R1. Open the server's **SYSLOG** service. You should see the "changed state to down" and "up" messages with times. What level are they?
6. On the server, open **Services → DNS**. Add an A record `web.lab.local` for the server's address. Give a PC this server as its DNS server. Ping `web.lab.local` from the PC.
7. Type `ip name-server 10.0.0.60` on R1, then `ping web.lab.local` on R1.

> [!sith] The dark side
> Using SNMPv2c with the community string `public`. It's the default on many devices, and it travels in plain text. Anyone on the network can read it and then ask your devices anything. With a read-write string, they can change settings too. Use SNMPv3, or at least a long, secret, read-only community.

## Check yourself

> [!question]- What does NTP do, and which port does it use?
> NTP keeps device clocks correct by getting the time from a time server. It uses UDP port 123.

> [!question]- What is an NTP stratum?
> The stratum is how many steps a clock is from a perfect time source. Stratum 1 is connected straight to the source, and a lower number is better.

> [!question]- What are the eight syslog severity levels, from 0 to 7?
> Emergency, alert, critical, error, warning, notification, informational and debugging.

> [!question]- Which syslog levels does logging trap warnings send?
> It sends level 4, warning, and everything more serious, so levels 0 to 4.

> [!question]- Which ports do syslog and SNMP use?
> Syslog uses UDP port 514. SNMP uses UDP port 161 for requests and UDP port 162 for traps.

> [!question]- What is an SNMP trap?
> A trap is a message a device sends to the monitoring system by itself, without being asked, to report an event.

> [!question]- Why is SNMPv3 better than SNMPv2c?
> SNMPv2c uses a community string sent in plain text. SNMPv3 uses usernames with authentication and encryption.

> [!question]- What is the difference between a DNS A record and an AAAA record?
> An A record maps a name to an IPv4 address. An AAAA record maps a name to an IPv6 address.

> [!question]- What does no ip domain-lookup do?
> It stops the router treating a mistyped command as a name to look up in DNS, which would make you wait.
