# 5.01 Securing Device Access

> [!abstract] Why this matters
> Anyone who logs in to a router controls your whole network. Strong passwords, encrypted logins and central accounts are the first defence. The exam expects you to set passwords correctly and explain AAA.

## Passwords on a device

```text
enable secret Str0ng-Enable!
service password-encryption
security passwords min-length 10
line console 0
 password Console-Pass-1
 login
 exec-timeout 5 0
line vty 0 4
 login local
 transport input ssh
login block-for 120 attempts 3 within 60
banner motd # Authorised access only. #
```

- `enable secret` protects privileged EXEC mode. It's stored as a strong hash.
- `enable password` does the same, but is stored in plain text. If both are set, `enable secret` wins. Don't use `enable password`.
- `service password-encryption` hides the plain-text passwords in the configuration with a weak scramble, called **type 7**. It stops someone reading over your shoulder, but it can be undone in seconds.
- `login block-for` stops logins for 120 seconds after 3 failures in 60 seconds. This slows down password guessing.
- `banner motd` shows a warning before login. MOTD means message of the day. A legal warning helps if you need to take action against an intruder.

## Password types in the configuration

| Type | Means | Safe? |
|---|---|---|
| 0 | Plain text | No |
| 7 | Weak scramble from service password-encryption | No |
| 5 | MD5 hash | Weak |
| 8 | PBKDF2 hash | Yes |
| 9 | scrypt hash | Yes |

Choose the type with `enable algorithm-type scrypt secret ...` where IOS supports it.

## Good passwords

Long passwords are stronger than short complex ones. Use a **passphrase** of several words. Turn on **multi-factor authentication**, MFA, where you can: something you know, like a password, and something you have, like a phone app. Certificates can also prove who someone is.

## AAA

AAA means **authentication, authorisation and accounting**.

- **Authentication**: who are you? Logging in.
- **Authorisation**: what are you allowed to do?
- **Accounting**: what did you do? A record of commands and logins.

Instead of local accounts on every device, AAA can check a central server.

| | RADIUS | TACACS+ |
|---|---|---|
| Standard | Open | Cisco |
| Transport | UDP 1812 and 1813 | TCP 49 |
| Encrypts | Only the password | The whole message |
| Separates authentication from authorisation? | No, combined | Yes |
| Best for | Network access, like Wi-Fi and 802.1X | Logging in to devices |

```text
aaa new-model
radius server LAB-RADIUS
 address ipv4 10.0.0.70 auth-port 1812 acct-port 1813
 key Radius-Key-1
aaa authentication login default group radius local
```

`group radius local` means "try the RADIUS server first, and use local accounts if it can't be reached".

## Lab

1. Open any lab with a router.
2. Type the password commands above.
3. Run `show running-config`. Find the `enable secret` line. It starts with `5`, `8` or `9`, then a hash. Find the console password: it's now type 7.
4. Exit and log back in on the console. Check you need the console password, then the enable secret.
5. Add a **Server-PT** at `10.0.0.70`. Under **Services → AAA**, turn it on. Add the router as a client, with the key `Radius-Key-1`, type RADIUS. Add a user.
6. On the router, type the AAA commands above. Log in on the console with the RADIUS user.

> [!sith] The dark side
> Trusting type 7 passwords. Websites can reverse them in a second. Anyone with a copy of your configuration has those passwords. Use `secret` wherever it exists, keep configuration backups safe, and treat type 7 as plain text.

## Check yourself

> [!question]- What is the difference between enable password and enable secret?
> enable password is stored in plain text. enable secret is stored as a strong hash, and wins if both are set.

> [!question]- What does service password-encryption do, and is it secure?
> It scrambles plain-text passwords in the configuration with type 7 encryption. It is not secure, because type 7 can be reversed in seconds.

> [!question]- What do the three As in AAA stand for?
> Authentication, which checks who you are. Authorisation, which decides what you may do. Accounting, which records what you did.

> [!question]- What are the main differences between RADIUS and TACACS+?
> RADIUS is an open standard using UDP, and only encrypts the password. TACACS+ is from Cisco, uses TCP port 49, encrypts the whole message, and keeps authentication and authorisation separate.

> [!question]- What does multi-factor authentication mean?
> Multi-factor authentication means you prove who you are with two or more different kinds of proof, such as a password and a code from your phone.

> [!question]- What does login block-for 120 attempts 3 within 60 do?
> It blocks all logins for 120 seconds if there are 3 failed attempts within 60 seconds, which slows down password guessing.
