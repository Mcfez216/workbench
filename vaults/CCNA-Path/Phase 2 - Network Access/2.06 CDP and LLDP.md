# 2.06 CDP and LLDP

> [!abstract] Why this matters
> CDP and LLDP let a device tell its neighbours what it is. When you're handed a network with no diagram, they show you what's plugged into what. That's often the first thing you do on a new network, and in exam troubleshooting labs.

## The idea

Each device sends a small message out of each port every so often. The neighbour on the other end saves it. The message says the device's name, its model, its IP address and which port it sent from.

| | CDP | LLDP |
|---|---|---|
| Full name | Cisco Discovery Protocol | Link Layer Discovery Protocol |
| Standard | Cisco only | Open standard, IEEE 802.1AB |
| On by default on Cisco | Yes | No |
| Sends every | 60 seconds | 30 seconds |
| Forgets after | 180 seconds | 120 seconds |

Both only see **directly connected** neighbours. They're Layer 2, so they don't cross routers.

## The commands

```text
show cdp neighbors
show cdp neighbors detail
lldp run
show lldp neighbors
show lldp neighbors detail
```

`detail` also shows the neighbour's IP address and software version.

To turn them off:

```text
no cdp run
interface g0/1
 no cdp enable
 no lldp transmit
 no lldp receive
```

## Security

These messages tell anyone listening exactly what your devices are. Turn them off on ports that face the internet or users.

## Lab

1. Open a lab with a router and two switches, like `2.03 ROAS.pkt`.
2. On the switch, run `show cdp neighbors`. You should see the router, its model, and the port on each side.
3. Run `show cdp neighbors detail`. Find the router's IP address.
4. Type `lldp run` on every device. Wait 30 seconds. Run `show lldp neighbors`.
5. Use only CDP to draw the network on paper: every device and every port.

> [!sith] The dark side
> Leaving CDP on a port that faces the internet or a guest network. An attacker learns your device models and software versions. Then they look up known bugs for that exact version. Turn CDP off on outside ports with `no cdp enable`.

## Check yourself

> [!question]- What is the difference between CDP and LLDP?
> CDP is Cisco's own neighbour discovery protocol and is on by default. LLDP is an open standard, IEEE 802.1AB, that works between different makers' devices and must be turned on with lldp run.

> [!question]- Which command shows a CDP neighbour's IP address?
> show cdp neighbors detail.

> [!question]- Can CDP see a device two routers away?
> No. CDP and LLDP only see directly connected neighbours.

> [!question]- Why would you turn CDP off on some ports?
> CDP tells anyone listening the model and software version of your device, which helps attackers. It should be off on ports that face the internet or untrusted users.
