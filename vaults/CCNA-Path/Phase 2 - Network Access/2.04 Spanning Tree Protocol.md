# 2.04 Spanning Tree Protocol

> [!abstract] Why this matters
> Networks have extra links between switches, so one broken cable doesn't stop everything. But a loop between switches makes broadcasts go round forever, and the network stops within seconds. Spanning Tree Protocol, or STP, blocks the extra links until they're needed. The exam asks you to work out which switch is the root and which ports block.

## Why loops are a disaster

Ethernet frames have no counter that runs out. A broadcast in a loop is copied by every switch, round and round. This is a **broadcast storm**. MAC address tables also keep changing, because the same address arrives on different ports.

## How STP decides

STP builds a tree with no loops. It works in four steps.

### 1. Elect the root bridge

Every switch has a **bridge ID**: a priority, then its MAC address. The **lowest** bridge ID wins and becomes the **root bridge**.

- The default priority is **32768**. Cisco adds the VLAN number to it. So in VLAN 10, the default is 32778.
- Priority goes up in steps of **4096**.
- If every priority is the same, the switch with the lowest MAC address wins. That's often the oldest switch, which is a bad choice. So set the root bridge yourself.

### 2. Each other switch picks one root port

The **root port** is the port with the lowest total cost to the root bridge. Faster links cost less.

| Speed | Cost |
|---|---|
| 10 Mbps | 100 |
| 100 Mbps | 19 |
| 1 Gbps | 4 |
| 10 Gbps | 2 |

If costs tie, the lowest neighbour bridge ID wins, then the lowest neighbour port ID.

### 3. Each link picks one designated port

On every link, the port with the lowest cost to the root becomes the **designated port**. It forwards. All ports on the root bridge are designated ports.

### 4. Everything else blocks

Any port that is neither a root port nor a designated port is **blocked**. In Packet Tracer, it has an orange light.

## Port states

The original STP is IEEE 802.1D. A port moves through these states:

| State | Forwards frames? | Learns MACs? | How long |
|---|---|---|---|
| Blocking | No | No | Up to 20 seconds, the max age |
| Listening | No | No | 15 seconds, the forward delay |
| Learning | No | Yes | 15 seconds |
| Forwarding | Yes | Yes | |

That's why a port can take 30 to 50 seconds to come up.

## Rapid STP

**Rapid PVST+** is Cisco's version of RSTP, IEEE 802.1w. It runs a separate tree in each VLAN and recovers in about a second.

- It has only three states: **discarding**, learning and forwarding.
- Extra roles: an **alternate port** is a ready backup for the root port. A **backup port** is a backup for a designated port on the same link.

## PortFast and BPDU Guard

Switches send STP messages called **BPDUs**, bridge protocol data units.

- **PortFast** makes a port go straight to forwarding. Use it only on ports to PCs and servers, never to switches.
- **BPDU Guard** shuts a PortFast port down if a BPDU arrives on it. That stops someone plugging a switch into a desk port and causing a loop.

## The commands

```text
spanning-tree mode rapid-pvst
spanning-tree vlan 10 root primary
spanning-tree vlan 20 priority 4096
interface fa0/1
 spanning-tree portfast
 spanning-tree bpduguard enable
 end
show spanning-tree
show spanning-tree vlan 10
```

`root primary` sets the priority low enough to win. `root secondary` makes a switch the backup root.

You can turn PortFast on for every access port at once with `spanning-tree portfast default`.

## Lab

1. Build three 2960 switches: SW1, SW2 and SW3. Connect them in a triangle with cross-over cables on their G0/1 and G0/2 ports.
2. Wait 30 seconds. One port has an orange light. That port is blocked.
3. Run `show spanning-tree` on each switch. Which switch is root? It says "This bridge is the root". Compare the MAC addresses and check that the lowest one won.
4. On SW3, type `spanning-tree vlan 1 root primary`. Run `show spanning-tree` again. SW3 is now root, and a different port blocks.
5. Delete one forwarding link. Watch the blocked port start forwarding.
6. Type `spanning-tree mode rapid-pvst` on all three switches, and repeat step 5. It recovers much faster.
7. Add a PC to SW1 Fa0/1. Turn on PortFast and BPDU Guard on that port. Then replace the PC with a switch. The port goes **err-disabled**, which means shut down because of an error. Bring it back with `shutdown` then `no shutdown`.

> [!sith] The dark side
> Leaving the root bridge to chance. With default priorities, the oldest, slowest switch often becomes the root, and traffic takes a poor path. Always set `spanning-tree vlan X root primary` on your core or distribution switch.

## Check yourself

> [!question]- What problem does STP solve?
> STP stops Layer 2 loops. Without it, extra links between switches cause broadcast storms and unstable MAC address tables.

> [!question]- How is the root bridge elected?
> The switch with the lowest bridge ID wins. The bridge ID is the priority followed by the MAC address, so if the priorities are the same, the lowest MAC address wins.

> [!question]- What is the default STP priority, and in what steps can you change it?
> The default priority is 32768, plus the VLAN number on Cisco switches. It can be changed in steps of 4096.

> [!question]- What is the STP cost of a 100 Mbps link and a 1 Gbps link?
> A 100 Mbps link costs 19 and a 1 Gbps link costs 4.

> [!question]- What is a root port?
> A root port is the one port on a non-root switch that has the lowest total cost to the root bridge.

> [!question]- What are the 802.1D port states, in order?
> Blocking, listening, learning and forwarding.

> [!question]- What are the RSTP port states?
> Discarding, learning and forwarding.

> [!question]- What do PortFast and BPDU Guard do?
> PortFast puts a port straight into forwarding, for ports that connect to end devices. BPDU Guard shuts the port down if an STP message arrives, which stops someone adding a switch and making a loop.

> [!question]- What is an alternate port in RSTP?
> An alternate port is a discarding port that is ready to take over at once if the root port fails.
