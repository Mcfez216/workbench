# 2.03 Inter-VLAN Routing

> [!abstract] Why this matters
> VLANs keep networks apart. But Sales still needs to reach the printer in IT and the internet. Inter-VLAN routing joins the VLANs again, through a router that can filter the traffic. There are two ways to do it, and the exam asks about both.

## Way 1: router on a stick

One router port connects to a trunk port on the switch. The router port is split into **subinterfaces**, one per VLAN. A subinterface is a virtual part of a real interface. Each one has the gateway address for its VLAN.

It's called "router on a stick" because one cable carries all the VLANs up to the router and back.

```text
interface g0/0
 no shutdown
interface g0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface g0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
interface g0/0.999
 encapsulation dot1Q 999 native
```

- `encapsulation dot1Q 10` tells the subinterface which VLAN tag it handles.
- The **physical** interface needs `no shutdown`. The subinterfaces then come up by themselves.
- The switch port facing the router must be a **trunk**.

The weak point is that one link carries all the traffic between VLANs.

## Way 2: a Layer 3 switch with SVIs

A multilayer switch can route by itself. Give it an SVI for each VLAN, and turn routing on.

```text
ip routing
interface vlan 10
 ip address 192.168.10.1 255.255.255.0
 no shutdown
interface vlan 20
 ip address 192.168.20.1 255.255.255.0
 no shutdown
```

This is faster, because the switch routes in hardware. It's how most office networks are built.

A Layer 3 switch port can also act like a router port, with no VLAN at all. This is called a **routed port**:

```text
interface g0/1
 no switchport
 ip address 10.0.0.1 255.255.255.252
```

## Lab part 1: router on a stick

1. Use your lab from [[2.02 Trunks and 802.1Q]], or build one switch with a Sales PC in VLAN 10 and an IT PC in VLAN 20.
2. Add a 2911 router. Connect its G0/0 to the switch's G0/2.
3. On the switch, make G0/2 a trunk: `switchport mode trunk`.
4. Type the router-on-a-stick commands above on the router.
5. Give the Sales PC the gateway `192.168.10.1`, and the IT PC the gateway `192.168.20.1`.
6. Ping from Sales to IT. It should work now.
7. Run `show ip route` on the router. You should see two connected networks, one per subinterface.
8. Save as `2.03 ROAS.pkt`.

## Lab part 2: Layer 3 switch

1. Build a 3560 switch with a Sales PC on Fa0/1 and an IT PC on Fa0/2.
2. Create VLANs 10 and 20, and put each port in its VLAN.
3. Type the SVI commands above, including `ip routing`.
4. Set the PCs' gateways to the SVI addresses.
5. Ping from Sales to IT. It should work with no router at all.
6. Run `show ip route`. You should see the two connected networks.
7. Save as `2.03 L3 Switch.pkt`.

> [!sith] The dark side
> Forgetting `ip routing` on the Layer 3 switch. The SVIs come up, and each PC can ping its own gateway. But nothing crosses between VLANs, because the switch isn't routing. If gateways work but other VLANs don't, check for `ip routing` first.

## Check yourself

> [!question]- What is router on a stick?
> Router on a stick is when one router interface, split into subinterfaces, routes between VLANs over a single trunk link to the switch.

> [!question]- What does encapsulation dot1Q 20 do on a subinterface?
> It tells the subinterface to handle frames tagged with VLAN 20, so it can act as the gateway for VLAN 20.

> [!question]- What must the switch port facing a router-on-a-stick router be?
> It must be a trunk port, so it can carry every VLAN to the router.

> [!question]- Which command makes a Layer 3 switch route between its SVIs?
> ip routing.

> [!question]- What does no switchport do on a Layer 3 switch port?
> no switchport turns the port into a routed port, which works like a router interface and can have its own IP address.

> [!question]- Why is a Layer 3 switch usually better than router on a stick?
> A Layer 3 switch routes in hardware and doesn't send every packet over a single link to a router, so it is faster and has no single busy link.
