# 2.01 VLANs

> [!abstract] Why this matters
> A VLAN splits one switch into several separate networks. Sales can't see IT's broadcasts, and you can keep traffic apart for security. Almost every real switch uses VLANs, and they're in many exam labs.

## An example first

One 24-port switch. Ports 1 to 8 are in VLAN 10, for Sales. Ports 9 to 16 are in VLAN 20, for IT.

- A Sales PC's broadcast only reaches other VLAN 10 ports.
- A Sales PC can't reach an IT PC at all, until a router joins the two VLANs.
- Each VLAN is its own broadcast domain, and gets its own IP network.

**VLAN** means virtual LAN. A LAN is a local area network.

## The facts to know

- VLAN numbers go from 1 to 4094.
- **VLAN 1** is the default. Every port starts in it. You can't delete it. For security, don't use it for users.
- VLANs 1002 to 1005 are kept for old network types. You can't use them.
- An **access port** belongs to one VLAN. PCs and printers connect to access ports.
- A **voice VLAN** lets one port carry a phone in one VLAN and the PC behind the phone in another.

## The commands

```text
vlan 10
 name SALES
vlan 20
 name IT
interface range fa0/1 - 8
 switchport mode access
 switchport access vlan 10
interface range fa0/9 - 16
 switchport mode access
 switchport access vlan 20
interface fa0/17
 switchport mode access
 switchport access vlan 10
 switchport voice vlan 150
 end
show vlan brief
```

`interface range` sets up many ports at once.

## The management address

A Layer 2 switch has one IP address, used only to manage it. It goes on an **SVI**, a switch virtual interface. An SVI is a virtual interface for a VLAN.

```text
interface vlan 99
 ip address 192.168.99.2 255.255.255.0
 no shutdown
ip default-gateway 192.168.99.1
```

The SVI only comes up if the VLAN exists and at least one port in that VLAN is up.

## Lab

1. Build one 2960 switch and four PCs. Connect them to Fa0/1, Fa0/2, Fa0/9 and Fa0/10.
2. Give all four PCs addresses in `192.168.1.0/24`: `.11`, `.12`, `.21` and `.22`.
3. Ping from `.11` to `.21`. It works, because all ports are in VLAN 1.
4. Type the commands above to create VLANs 10 and 20.
5. Ping `.11` to `.21` again. It fails now. They're in different VLANs.
6. Ping `.11` to `.12`. It still works. They're both in VLAN 10.
7. In the real world, each VLAN would have its own network. Change the IT PCs to `192.168.20.21` and `.22`, and the Sales PCs to `192.168.10.11` and `.12`. You'll join them with a router in [[2.03 Inter-VLAN Routing]].
8. Type `show vlan brief`. Check each port is in the VLAN you expect.

> [!sith] The dark side
> Typing `switchport access vlan 30` when VLAN 30 doesn't exist yet. A real switch creates it for you, but with no name. In Packet Tracer and on the exam, create and name every VLAN first, then add the ports. Then check with `show vlan brief`.

## Check yourself

> [!question]- What does a VLAN do?
> A VLAN splits one physical switch into several separate networks. Each VLAN is its own broadcast domain.

> [!question]- What is the default VLAN, and why shouldn't users be in it?
> VLAN 1 is the default VLAN. Every port starts in it and it can't be deleted. Users shouldn't be in it, because attackers know every port starts there.

> [!question]- What two commands put a port into VLAN 10 as an access port?
> switchport mode access, then switchport access vlan 10.

> [!question]- Which command shows every VLAN and the ports in each one?
> show vlan brief.

> [!question]- Can two PCs in different VLANs reach each other through one Layer 2 switch?
> No. Traffic between VLANs must go through a router or a Layer 3 switch.

> [!question]- What is a voice VLAN?
> A voice VLAN lets one switch port carry an IP phone's traffic in one VLAN and the traffic of the PC plugged into the phone in another VLAN.

> [!question]- What is an SVI on a Layer 2 switch used for?
> An SVI, or switch virtual interface, gives the switch an IP address in a VLAN so that you can manage it remotely.
