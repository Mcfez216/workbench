# 2.07 Wireless Basics

> [!abstract] Why this matters
> Most users connect over Wi-Fi now. The exam asks about radio bands, how access points are managed, and how Wi-Fi is secured. You may also have to set up a WLAN on a controller in a lab.

## The words

- A **WLAN** is a wireless LAN.
- The **SSID** is the network's name, the one you pick on your phone.
- A **BSS**, basic service set, is one access point and its clients. The access point's MAC address on the radio is the **BSSID**.
- An **ESS**, extended service set, is several access points with the same SSID, so you can walk between them. Moving between them is **roaming**.
- Wi-Fi standards are called **IEEE 802.11**. Newer versions are 802.11n (Wi-Fi 4), ac (Wi-Fi 5), ax (Wi-Fi 6 and 6E) and be (Wi-Fi 7).

## The radio bands

| Band | Range | Speed | Channels that don't overlap |
|---|---|---|---|
| 2.4 GHz | Further, goes through walls better | Slower, more interference | Only **1, 6 and 11** |
| 5 GHz | Shorter | Faster | Many |
| 6 GHz | Shortest | Fastest | Many. Wi-Fi 6E and 7 only. |

Next-door access points should use channels that don't overlap. On 2.4 GHz, that means 1, 6 and 11.

## How access points are managed

- An **autonomous AP** is set up on its own. Fine for a small office.
- A **lightweight AP** is controlled by a **WLC**, a wireless LAN controller. You set up everything once on the WLC.
- The AP and WLC talk through a tunnel called **CAPWAP**. It uses UDP 5246 for control and UDP 5247 for data.
- In **split-MAC**, the AP handles the fast radio work, and the WLC handles logins, security and settings.
- A **cloud-managed AP**, like Cisco Meraki, is controlled from a website.

### AP modes

| Mode | What it does |
|---|---|
| Local | The normal mode. Serves clients and tunnels traffic to the WLC. |
| FlexConnect | Serves clients and can send traffic straight onto the local network if the WLC link fails. For branch offices. |
| Monitor | Doesn't serve clients. Only listens, to find rogue APs and attacks. |
| Sniffer | Captures wireless traffic and sends it to a computer for study. |
| Bridge | Joins two buildings by radio. |

### WLC ports

On a WLC, the cable to the switch is usually a trunk. It carries the management VLAN and one VLAN for each WLAN. Several WLC ports can be bundled with **LAG**, link aggregation, which is the WLC's word for EtherChannel.

## Wi-Fi security

| Standard | Encryption | Notes |
|---|---|---|
| WEP | RC4 | Broken. Never use it. |
| WPA | TKIP | Old. Don't use it. |
| WPA2 | AES with CCMP | Still common |
| WPA3 | AES with GCMP, and SAE | The newest and best. SAE protects even weak passwords against guessing. |

Each WPA version has two ways to log in:

- **Personal**, or PSK, a pre-shared key. Everyone uses one password. For homes and small offices.
- **Enterprise**, or **802.1X**. Each user logs in with their own account, checked by a **RADIUS** server. For businesses.

## Lab: a wireless office

1. Put a **Home Router** in the workspace. It's under Network Devices → Wireless Devices. Add a **Laptop-PT** and a **Smartphone-PT**.
2. Click the laptop. On the **Physical** tab, turn it off with the power button. Drag out the wired card and drag in the **WPC300N** wireless card. Turn it back on.
3. Click the Home Router → **GUI** tab. Under **Wireless**, set the SSID to `CCNA-LAB`. Under **Wireless Security**, choose **WPA2 Personal**, AES, and the passphrase `Packet-Tracer-1`. Save.
4. On the laptop, open **Desktop → PC Wireless**. Connect to `CCNA-LAB` with the passphrase.
5. Check the laptop got an IP address from the Home Router's DHCP server, under **IP Configuration**.
6. Connect the smartphone the same way, from its **Config → Wireless0** settings.
7. Ping the smartphone from the laptop.
8. Extra: Packet Tracer has a **WLC-2504** and **LAP-PT** lightweight APs. Try joining a LAP to a WLC on the same VLAN, and creating a WLAN in the WLC's web page from a PC's browser.

> [!sith] The dark side
> Using WPA2 Personal for a whole company. Everyone shares one password, so when someone leaves, you must change it on every device. And anyone with the password can read others' traffic more easily. Businesses should use WPA2 or WPA3 Enterprise with 802.1X.

## Check yourself

> [!question]- Which 2.4 GHz channels don't overlap?
> Channels 1, 6 and 11.

> [!question]- What is the difference between an SSID and a BSSID?
> The SSID is the network name that users see. The BSSID is the MAC address of one access point's radio.

> [!question]- What is CAPWAP, and which ports does it use?
> CAPWAP is the tunnel between a lightweight access point and its wireless LAN controller. It uses UDP port 5246 for control and UDP port 5247 for data.

> [!question]- What is the difference between an autonomous AP and a lightweight AP?
> An autonomous AP is set up and managed on its own. A lightweight AP is set up and controlled by a wireless LAN controller.

> [!question]- What does FlexConnect mode do?
> FlexConnect lets an access point in a branch office send client traffic straight onto its local network, and keep working if its link to the WLC fails.

> [!question]- What is the difference between WPA2 Personal and WPA2 Enterprise?
> WPA2 Personal uses one shared password for everyone. WPA2 Enterprise gives every user their own login, checked by a RADIUS server using 802.1X.

> [!question]- What does WPA3 add over WPA2?
> WPA3 uses SAE instead of a pre-shared key handshake, which protects against password guessing, and uses stronger GCMP encryption.

> [!question]- What is an ESS?
> An ESS, or extended service set, is several access points using the same SSID, so users can roam between them.
